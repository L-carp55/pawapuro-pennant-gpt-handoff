# 走力査定・次チャット用ハンドオフ（2026-08-08）

## 目的
次チャットでは、走力査定の未解決点だけを継続する。過去の試行錯誤は引き継がなくてよい。

## 走力の定義（固定）
- 走力 = **最初の走行ステップから90ft（27.43m）前後を直線的に速く移動する身体的スプリント能力**。
- 含む: 短距離加速、最高速度、90ft付近での速度維持。
- 含めない: 盗塁の読み・スタート技術、走塁判断、ベースランニング技術、スライディング、スイング→走行移行、バント開始、守備の反応/打球判断。
- 盗塁・走塁・内野安打○などは別能力として分離する。
- 50m走の秒数をそのまま能力値へ変換しない。

## 現在のv3物理スケール
PowerPro値を使わずに作った暫定物理尺度。

- 2022 MLB Statcast 90ft Running Splitsの観測レンジを1〜100へ線形対応。
- fast anchor: T90=3.66秒 → 100
- slow anchor: T90=4.78秒 → 1
- 式:
  `rating = clamp(1,100,100 - 99*(T90-3.66)/(4.78-3.66))`

MLB物理ブリッジ（2022、Sprint Speedと実T90が両方あるNPB接続26人）:
- `T90 = 7.117945 - 0.111415 * SprintSpeed_ftps`
- R² ≈ 0.934
- Sprint Speed + T30ならR² ≈ 0.981、LOO MAE ≈ 0.021秒まで改善。→ **加速情報は本当に重要**。

## NPB+最高速度の暫定ブリッジ
NPB+の「瞬間最高速度」とMLB Sprint Speedは公開定義が同一とは確認できないため、絶対値を直接同一視しない。

暫定v3:
- `T90 = 4.05 - 0.1015374380*(top_speed_kmh - 31.6)`
- 31.6km/hをT90 4.05秒へ中心合わせ。
- PowerPro値はこの式の作成に不使用。

## 99人の独立QA（重要）
2026 NPB+最高速度がある100人のうち、PowerPro 2026と99人を名寄せ。
**先にv3式を99人へ一括適用し、その後でPowerProと比較。**

結果:
- 独自v3平均: **65.45**
- PowerPro平均: **65.67**
- 平均差: **-0.22点**
- 相関: **r=0.766**
- MAE: **7.95点**
- ±10点超の差: 36/99人
- ±15点超: 13/99人

速度帯平均:
- 29.0–29.9km/h: 独自45.1 / PowerPro43.3
- 30.0–30.9: 55.4 / 52.6
- 31.0–31.9: 64.4 / 66.7
- 32.0–32.9: 73.2 / 74.3
- 33.0–33.9: 81.3 / 83.5

結論:
- **1〜100の目盛りはかなり妥当。** 「50=NPB平均」は誤り。
- 平均的NPB野手が結果的に60台半ばになるのは、PowerProへ合わせなくても物理尺度から自然に出る。
- 残る主要問題は、**最高速度だけでは個人の90ft加速能力を表し切れないこと**。

## 最速一塁到達は補正に使わない
NPB+最速H→1を top speed + 左右打席 + 犠打率 で補正した残差は、PowerProとの差をほぼ説明しなかった（r≈0.061）。
- セーフティバント、スイング→走行移行などの汚染が強い。
- 最速H→1は基本走力の加速補正には使わない。

- 平均 6.3549秒
- 中央値 6.35秒
- SD 0.2655秒
- 範囲 5.82〜6.93秒

### 野球専用27.43m研究
大学野球選手36人を、野球場内野土・スパイク・野球のリード姿勢・Brower光電管で測定した研究:
- 27.43m平均: **4.11±0.13秒**
- 範囲: 3.79〜4.38秒
- 25m付近まで加速が続く。
- 論文自身が「野球では最大速度より加速（ダッシュ力）を重視」とする。
- 内外野手だけの27.43m中心は推定約4.06秒（論文直接値ではないのでcandidate_only）。

この研究は現在のT90定義を強く支持。

## 50m→T90のcandidate prior
PowerPro非依存。
- `z50 = (t50 - 6.354912)/0.265506`
- `T90_prior = 4.0575 + 0.100750285*z50`

注意:
- raw秒数を距離比例変換していない。
- 50m集団内順位を野球27.43m集団内順位へ写すPrior。
- **productionではまだ未使用**。

PowerPro後置きQAでは3人のMAEが top-speed-only 8.97 → 50m prior 6.95へ改善したが、ほぼ林1人の改善。**50mを全員へ一律加点する根拠にはならない。**

## 現在の判断
- 最高速度 = 主材料
- cleanなT10/T30/30m/標準化50m = 加速profileの独立材料
- 両者の統合weightはまだ決めない
- top speed と acceleration prior が0.05秒以上食い違う場合、profile flagを立てる候補
- ポジション補正は走力へ入れない
- PowerPro/プロスピ値を査定式へ直接入れない
- プロスピは基本的にPowerProと同系統なので、今後の基準作成ではわざわざ参照しない
