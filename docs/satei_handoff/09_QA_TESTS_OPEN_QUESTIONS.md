## 1. 絶対に防ぐ回帰

### Q1. 500AB誤用

```python
assert hr_500pa_equivalent(10, 436) ≈ 10
assert hr_500pa_equivalent(10, 500) ≈ 8.725
```

500を掛ける実装を検出。

### Q2. 盗塁数が走力へ直接入らない

同じ速度入力でSBだけ変えても走力は不変。

### Q3. 三振二重減点

三振赤特ON時、K%減点と赤特減点を二重に適用しない。

### Q4. エラーが守備力を下げない

Range入力が同じでEだけ変化した場合:

- 守備力不変
- 捕球変化

### Q5. 外野の逆補正

同じ現実Rangeで:

```text
走力高 → 推定守備力低
走力低 → 推定守備力高
```

単調性をproperty test。

### Q6. 内野では補正が小さい

同じRange・走力差で、外野より守備力差が小さい。

### Q7. チャンス/対左二重計上

Tier Aの`AVG_vsR_nonRISP`を使った場合、チャンスBを理由にMを再減点しない。

### Q8. 周辺集計からクロスを捏造しない

Tier Bで`AVG_vsR_nonRISP`が生成されないこと。

### Q9. ケガPrior

同じ300PA高成績でも:

- 実績豊富なケガ離脱
- 新人限定起用

で前者の縮小が小さい。

### Q10. GG不使用

入力にGG列があっても能力結果が変わらない。

### Q11. RBI不使用

RISP等を固定してRBIだけ変えてもチャンスランク不変。

### Q12. 金特制限

通常タイトル級だけでは金特が自動付与されない。

### Q13. KONAMIブラインド

freeze前にKONAMI入力を参照しようとするとエラー。
