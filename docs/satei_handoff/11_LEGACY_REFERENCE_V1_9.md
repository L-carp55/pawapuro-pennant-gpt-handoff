# パワプロ査定プロジェクト参照仕様書 v1.9

作成日: 2026-05-09  
用途: 次セッション以降で、パワプロ野手査定モデルを継続するための参照ファイル。  
対象: NPB現役、2015年以降のパワプロ実装査定、平成・昭和・戦前OB、MLB選手、日本人以外のMLB選手。

---

## 0. このファイルの使い方

次セッションでは、このファイルを前提にして査定・比較・モデル改良を進める。

毎回、選手査定では原則として以下を出す。

```text
選手・年
実成績
補正成績：2019年NPB換算
査定能力：弾道 / ミート / パワー / 走力 / 肩力 / 守備力 / 捕球
得能候補：青特 / 赤特 / 金特
コメント：補正成績と能力値がズレる理由、得能による分解、不可解な点
```

特に打撃査定では、以下の形式を基本にする。

```text
実成績：
G, PA, AB, AVG, OBP, SLG, OPS, 2B, 3B, HR, BB, SO, SB

補正成績：
2019年NPB換算 AVG*
2019年NPB換算 HR500AB*
可能なら ISO*, SLG*, OPS*

査定：
弾道 / M / P

得能候補：
チャンス、対左、AH、PH、広角、三振、併殺、選球眼など

コメント：
なぜそのM/Pになったか
補正打率・補正本塁打数と査定能力の乖離理由
チャンス/対左/得能で基礎能力をどう調整したか
```

## 1. 基本思想

### 1.1 目的

目的は、実在野手をパワプロ風に査定すること。  
ただし、単なるKONAMI表示能力の再現ではなく、現実の成績・時代補正・リーグ補正・得能分解を考慮して、納得感のある査定を作る。

### 1.2 重要な分離

以下を混同しない。

```text
補正成績
= 年度・リーグ・時代・球場・短期シーズン・疲労などを補正した成績

平均得能込み基準
= その成績帯の選手に平均的な得能が付いていると仮定した能力基準

個別査定能力
= その選手に実際に付ける得能の量・種類を踏まえた基礎能力

実効能力
= 基礎能力 + 得能効果
```

ユーザーが提示したミート・パワー基準は、**平均得能込み基準**として扱う。  
つまり、成績に直接対応するのは「得能込み平均」の能力であって、得能なしの純粋能力ではない。

## 2. 補正成績の基準年

補正成績は原則として **2019年NPB換算** で出す。

理由:

```text
・現代野球に近い
・143試合制
・2023〜2025ほど極端な打低ではない
・2018ほど打高でもない
・現代の投手レベル、打撃環境に比較的近い
```

2025年は打低すぎるため、補正基準年としては不向き。  
2020年は120試合制なので基準年としてはやや特殊。

暫定基準値:

```text
AVG_ref_2019 ≒ .253
HR500AB_ref_2019 ≒ 15本級
```

## 3. 補正成績の算出方法 v1.9

今後、査定時には可能な限りこの式を文章とともに説明する。

### 3.1 実成績

まず元成績を出す。

```text
G
PA
AB
AVG
OBP
SLG
OPS
2B
3B
HR
BB
SO
SB
主守備位置
守備イニング
```

古い年度でPAが不明なら、PAは推定する。

```text
PA_est ≒ AB + BB + HBP + SH + SF
```

詳細がない戦前・古い年度では暫定的に、

```text
PA_est ≒ AB × 1.08〜1.15
```

とする。ただし、PA推定であることをコメントに明記する。

---

### 3.2 平常時成績化

ミートは総打率ではなく、理想的には **対右・非得点圏** の打率を基準にする。

理想:

```text
AVG_neutral_raw = AVG_vsR_nonRISP
```

データがない場合の近似:

```text
AVG_neutral_raw
≈ AVG_total
- w_L × (AVG_vsL - AVG_vsR)
- w_RISP × (AVG_RISP - AVG_nonRISP)
```

考え方:

```text
チャンスA/Bが高い選手
→ 総打率の一部を得点圏で稼いでいる
→ 基礎ミートは下げ、チャンスで戻す

チャンスF/Gが低い選手
→ 平常時は総打率より打っている可能性
→ 基礎ミートは上げ、チャンス赤特で下げる

対左A/Bが高い選手
→ 対左で稼いでいる
→ 基礎ミートは下げ、対左で戻す

対左F/Gが低い選手
→ 対右・平常時は総打率より高い可能性
→ 基礎ミートは上げ、対左赤特で下げる
```

パワーも同様に、理想は対右・非得点圏の本塁打率。

```text
HR500AB_raw = HR / AB × 500
```

```text
HR500AB_neutral_raw
≈ HR500AB_raw
- LeftPowerEffect
- ChancePowerEffect
```

ただし、本塁打はサンプルが小さいため、チャンス/対左によるパワー補正はミートより控えめにする。

### 3.3 2019年NPB換算

#### 打率

```text
AVG*_neutral
= AVG_ref_2019
× {1 + Q_AVG × (AVG_neutral_raw / AVG_lg_year - 1) + L_AVG}
```

意味:

```text
AVG_ref_2019:
  2019年NPB基準打率。暫定 .253

AVG_lg_year:
  対象年度・対象リーグの平均打率

Q_AVG:
  そのリーグ・時代の傑出度倍率

L_AVG:
  リーグ平均水準の差。MLB→NPB変換や古い時代補正で使う
```

#### 本塁打

本塁打率は打席ではなく打数基準にする。  
理由は、四球が多い強打者を不利にしないため。

```text
HR500AB_raw = HR / AB × 500
```

2019年NPB換算:

```text
HR500AB*_neutral
= HR500AB_neutral_raw
× (HR500AB_ref_2019 / HR500AB_lg_year)^γ_HR
× LeaguePowerFactor
× ParkFactor
```

暫定値:

```text
HR500AB_ref_2019 ≒ 15本級
γ_HR = 0.45〜0.60
```

γを1.0にしない理由:

```text
・本塁打環境はボール、球場、時代、戦術に大きく左右される
・完全補正すると、戦前や特殊年で数本の差が暴れすぎる
・投打環境補正は入れるが、過補正は避ける
```

### 3.4 短期シーズン・サンプル補正

固定500打席だと戦前・短縮シーズンが不利になる。  
しかし、35試合制の.369と143試合制の.369を同格にはしない。

そのため、3種類の係数を使う。

```text
TargetPA_y = 500 × TeamGames_y / 143
```

```text
R_rel = min(1, sqrt(PA / TargetPA_y))
R_abs = min(1, sqrt(PA / 500))
R_len = sqrt(TeamGames_y / 143)
```

意味:

```text
R_rel:
  そのシーズン内で十分出場しているか

R_abs:
  絶対的なサンプル量があるか

R_len:
  シーズン自体の長さ。35試合制などは低くなる
```

ミート用:

```text
W_M = 0.50 × R_abs + 0.35 × R_rel + 0.15 × R_len
```

パワー用:

```text
W_P = 0.60 × R_abs + 0.25 × R_rel + 0.15 × R_len
```

補正成績をPrior側へ戻す。

```text
AVG*_sample
= PriorAVG* + W_M × (AVG*_neutral - PriorAVG*)
```

```text
HR500AB*_sample
= PriorHR500AB* + W_P × (HR500AB*_neutral - PriorHR500AB*)
```

Priorは以下を使う。

```text
・過去3年成績
・周辺年度の成績
・同時代リーグ平均寄りの値
```

実績補正は、選手を実力以上に盛るものではない。  
長期安定により単年の上振れ/下振れを安定化させるために使う。

### 3.5 疲労補正

疲労補正は能力値に後付けせず、補正成績に混ぜる。  
ただし、短期シーズンでフル出場しただけで大きく補正しないよう、相対負荷と絶対負荷を両方見る。

```text
BatLoad_rel = PA / TargetPA_y
BatLoad_abs = PA / 500
```

守備負荷:

```text
DefLoad_rel = DefInn / (9 × TeamGames_y) × PositionLoad
DefLoad_abs = DefInn / (9 × 143) × PositionLoad
```

ポジション負荷:

| 守備位置 | PositionLoad |
|---|---:|
| 捕手 | 1.35 |
| 遊撃手 | 1.20 |
| 二塁手 | 1.12 |
| 中堅手 | 1.10 |
| 三塁手 | 1.05 |
| 右翼手 | 1.00 |
| 左翼手 | 0.98 |
| 一塁手 | 0.92 |
| DH | 0.70 |

疲労スコア:

```text
FatigueScore
= clamp(
    0.5 × max(0, BatLoad_rel - 1.05)
  + 0.5 × max(0, BatLoad_abs - 1.00)
  + 0.4 × max(0, DefLoad_rel - 0.90)
  + 0.4 × max(0, DefLoad_abs - 0.70)
  + 0.4 × max(0, CareerLoad3 - 1.10),
  0,
  3
)
```

3年負荷:

```text
CareerLoad3
= 0.50 × SeasonLoad_this
+ 0.30 × SeasonLoad_last
+ 0.20 × SeasonLoad_two_years_ago
```

疲労補正を補正成績に混ぜる。

```text
AVG*_final
= AVG*_sample + 0.003 × FatigueScore
```

```text
HR500AB*_final
= HR500AB*_sample × (1 + 0.015 × FatigueScore)
```

最大でも、

```text
AVG +.009程度
HR500AB +4〜5%
```

に抑える。

## 8. 弾道基準

弾道はパワーとは別に見る。

| 弾道 | 目安 |
|---:|---|
| 1 | 極端なゴロ型、長打少ない、HRほぼなし |
| 2 | 標準〜単打・中距離型 |
| 3 | 二塁打・本塁打が一定以上、ISO中〜高 |
| 4 | HR500AB高い、FB%、Barrel%、打球角度が高い |

MLB現代選手は Launch Angle、Barrel%、xSLG を使う。  
NPBや古い選手は、HR、2B、3B、SLG、ISO、打撃タイプの記録から推定する。

## 9. チャンス・対左の考え方

かなり重要。

### チャンス

```text
ΔChance = AVG_RISP - AVG_nonRISP
```

| ΔChance | チャンス |
|---:|---|
| +.090以上 | A候補 |
| +.050〜+.089 | B |
| +.020〜+.049 | C寄り |
| −.019〜+.019 | D |
| −.020〜−.049 | E |
| −.050〜−.089 | F |
| −.090以下 | G候補 |

ただし、得点圏はブレが大きい。  
単年だけなら弱め、複数年継続なら強め。

### 対左

```text
ΔLeft = AVG_vsL - AVG_vsR
```

| ΔLeft | 対左 |
|---:|---|
| +.080以上 | A候補 |
| +.045〜+.079 | B |
| +.020〜+.044 | C寄り |
| −.019〜+.019 | D |
| −.020〜−.044 | E |
| −.045〜−.079 | F |
| −.080以下 | G候補 |

ミート/パワーの処理:

```text
チャンス・対左が高い
→ 総成績より平常時成績は低い
→ 基礎M/Pを下げ、得能で戻す

チャンス・対左が低い
→ 総成績より平常時成績は高い
→ 基礎M/Pを上げ、赤特で下げる
```

## 10. 守備力・捕球へのポジション負荷反映

ポジション負荷は打撃補正には小さく、守備力・捕球には比較的大きく効かせる。

### 守備力

まずポジション内評価。

```text
FieldingBase
= 守備範囲・反応・守備指標・守備機会から算出
```

現代なら:

```text
UZR
DRS
OAA
RngR
守備得点
```

古い選手なら:

```text
守備率
刺殺
補殺
守備機会
併殺参加
ポジション別平均
```

守備仕事量:

```text
DefWork
= DefInn / (9 × TeamGames_y) × PositionLoad
```

| DefWork | 守備力補正 |
|---:|---:|
| 0.4未満 | 0 |
| 0.4〜0.7 | +0〜1 |
| 0.7〜0.9 | +1〜2 |
| 0.9〜1.1 | +2〜4 |
| 1.1以上 | +3〜5 |

ただし、守備内容が平均以上の場合のみ。  
守備指標が悪いのに多く守った場合は、守備力を上げず、起用量として評価する。

### 捕球

```text
FPCT = (PO + A) / (PO + A + E)
```

```text
FPCT_Z
= (FPCT_player - FPCT_pos_year_avg) / FPCT_pos_year_sd
```

```text
C_base = 55 + 8 × FPCT_Z
```

守備機会・負荷補正:

```text
ChanceLoad = DefensiveChances / PosAverageChances
CatchWork = 0.6 × ChanceLoad + 0.4 × DefWork
```

| CatchWork | 捕球補正 |
|---:|---:|
| 0.5未満 | −2〜0 |
| 0.5〜0.8 | 0〜+1 |
| 0.8〜1.1 | +1〜3 |
| 1.1〜1.4 | +3〜5 |
| 1.4以上 | +4〜7 |

同じ守備率.990でもポジションで評価を変える。

| 守備率.990 | 捕球評価 |
|---|---:|
| 一塁手 | E〜D |
| 外野手 | C前後 |
| 捕手 | D〜C |
| 二塁手 | C〜B |
| 遊撃手 | C〜B |
| 三塁手 | B〜A |


| 0 | 35 |
| 1 | 45 |
| 2 | 55 |
| 3 | 65 |
| 4 | 75 |

| 6 | 95 |
| 8 | 115 |
| 10 | 135 |

WARの構成要素を能力に対応させる。

```text
打撃貢献 → M/P/選球眼/得能
走塁貢献 → 走力/走塁/盗塁
守備貢献 → 守備力/肩力/捕球/送球
ポジション補正 → 総合価値に入れる
稼働率 → ケガしにくさ・疲労補正
```

## 12. MLB補正

MLB成績はそのままNPBに置かない。  
必ず、MLB年度環境・MLB時代レベル・2019NPB基準への変換を行う。

特に2004イチローのようなケース:

```text
実成績:
.372 / 8 HR / 704 AB / 762 PA

そのまま:
.372, 8本

2019NPB換算:
AVG* .385〜.395前後
HR500AB* 6〜8本級
```

2004MLBは20年前なので現代MLBより少し割り引くが、NPB 2019よりは水準が高い。  
したがって、MLB .372 を NPB .370台前半程度に置くのは低すぎる。

## 13. 戦前・短期シーズンの扱い

不確実性を `±` で出すことは基本しない。  
能力査定が目的なので、最終的には1つの値を出す。

ただし、短期シーズンを満額評価しすぎない。

考え方:

```text
143試合制で500打席 .369
→ 満額評価

35試合制で約140打席 .369
→ 高評価だが、Prior側に戻す

固定500打席基準をそのまま当てる
→ 厳しすぎる

試合数比だけで500打席相当にする
→ 甘すぎる

R_abs + R_rel + R_len の混合で中間処理
→ 採用
```

## 14. 実績補正

実績補正は能力を実力以上に盛るものではない。

用途:

```text
長期安定
→ 単年不調でも下げすぎない

単年だけ突出
→ いきなり満額評価しない

複数年で同じ傾向
→ 能力レンジを狭める

短期・戦前・記録不足
→ Prior側に戻す
```

OBや全盛期カードでは、単年ではなく周辺年度も見る。

```text
Skill_prime
= 0.50 × Best3YearAvg
+ 0.30 × BestSingleYear
+ 0.20 × Best5YearAvg
```

ただし、この式は「盛る」ためではなく、ピーク能力を安定推定するため。

## 17. 出力時の注意

査定結果では、必ず以下を書く。

```text
・実成績
・補正成績
・査定M/P
・弾道
・得能候補

```

補正成績の算出方法は毎回、文章と数式で説明する。

特にコメントでは以下を明示する。

```text
・補正打率とミートの関係
・補正HR500ABとパワーの関係
・K%、ISO、SLG、OPS、BB%、2B/3Bなどの影響
・チャンス/対左で基礎能力を削ったか盛ったか
・得能量が同成績帯の平均より多いか少ないか
・疲労補正やポジション負荷をどう反映したか
・KONAMI実装とズレる場合、そのズレが説明可能か不可解か
```

## 18. このプロジェクトで避けるべきこと

```text
・打率だけでミートを決める
・本塁打数だけでパワーを決める
・PAとABの役割を混同する
・チャンス/対左を無視して総打率からミートを出す
・戦前の短期シーズンを固定500打席基準で極端に下げる
・逆に短期シーズンを試合数比だけで満額評価する
・守備率だけで捕球を決める
・守備負担を打撃に大きく足しすぎる
・KONAMI能力を正解として扱う
・レジェンド補正や人気補正で盛る
```

## 19. 現時点の最終方針

```text
補正成績：
2019年NPB換算を基準にする。

ミート：
平常時打率、500打席相当、チャンス/対左、K%、Contact、内野安打で補正。

パワー：
HR/AB基準、2019年NPB換算、ISO/SLG/2B/3B/球場で補正。

疲労：
能力に後付けせず、補正成績に小さく混ぜる。

ポジション負荷：
打撃には小さく、守備力・捕球には比較的大きく。

短期シーズン：
R_abs, R_rel, R_len の混合でPrior側に戻す。

得能：
平均得能込み基準との差で基礎能力を調整する。

KONAMI比較：
特能で説明可能か、査定ノイズかを分解する。
```
