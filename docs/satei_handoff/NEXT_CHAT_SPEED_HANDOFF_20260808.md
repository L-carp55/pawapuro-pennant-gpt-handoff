# 次チャット用：走力査定 引き継ぎ（2026-08-08）

このファイルは、同じパワプロ査定プロジェクト内で次チャットへ移るための**差分だけ**を残す。既存のプロジェクトルール・一般仕様は重複記載しない。

## 今の目的

2024年の8選手を含む走力査定を、盗塁・走塁技術から分離した**純粋な野球内スプリント能力**として完成させる。

### 走力の定義

**最初の走行ステップから90ft（27.43m）前後を直線移動する身体的スプリント能力。**

含む：
- 初速・加速
- 最高速度
- 約90ftまでの速度維持

含めない：
- 盗塁判断・リード・スタート技術
- 走塁判断・ベースランニング技術
- スイング→走行への移行
- セーフティバント由来の一塁到達短縮
- UBR、追加進塁、盗塁数/成功率、三塁打などの結果指標
- 守備位置補正

## 重要な修正点

### 1. 「走力50＝NPB平均」は撤回

旧案のpercentile中心50方式は低すぎた。

PowerProを使わず作った現在の物理尺度を2026 NPB+ 99人へ一括適用すると：
- 独自v3平均 **65.45**
- PowerPro 2026同一99人平均 **65.67**
- 平均差 **-0.22**
- 相関 **0.766**
- MAE **7.95点**

→ 全体スケールはかなり自然。問題は主に**個人ごとの加速/最高速度profile**。

参照：
- `outputs/derived/speed_blind_v3_npbplus_2026.json`
- `outputs/derived/speed_blind_v3_powerpro_qa_2026.json`

### 2. PowerProは外部QA専用

今後、個別PowerPro走力やPowerPro回帰係数を**査定式の学習・補正に使わない**。

手順：
1. 物理データだけで査定を凍結
2. その後でPowerProと答え合わせ

プロスピは基本的にPowerProと同系統なので、基準作成では見なくてよい。

## 現在のv3物理スケール

2022 MLB Statcast 90ft Running Splitsの実測レンジを1〜100へ線形対応：

- T90 3.66秒 = 100
- T90 4.78秒 = 1

式：
`rating = clamp(1,100,100 - 99*(T90-3.66)/(4.78-3.66))`

MLB Sprint Speed → T90（2022、NPB接続26人）：
`T90 = 7.117945 - 0.111415 * SprintSpeed_ftps`
- R² ≈ 0.934

重要：NPB+のkm/hはMLB Sprint Speedと定義同一と確認できないため、単位変換して直接入れない。

暫定NPB+ bridge：
`T90 = 4.05 - 0.1015374380*(top_speed_kmh-31.6)`

これはPowerPro非依存。中心4.05秒は後から2017大学野球研究ともほぼ整合した。

## 加速profileの新しい根拠

2017年の大学野球選手36人研究：
- 野球場内野土
- スパイク
- 野球のリード姿勢
- Brower光電管
- 30mを5mごと測定

報告：
- 27.43m平均 **4.11±0.13秒**
- 範囲 **3.79〜4.38秒**
- 25m付近まで加速継続
- 論文も野球では最大速度より加速（ダッシュ力）が重要とする

内外野手だけから推定したposition-player中心は約 **4.06秒**（これは推論値で直接報告ではない）。

参照：
- `configs/speed_acceleration_prior.json`

## 現在の判断

走力の1〜100目盛りは大きくは問題なさそう。
残る主課題は：

> **最高速度型と加速型を、PowerProを使わずにどう区別し、T90へ統合するか。**

現時点では：
- top speed = 主材料
- cleanなT10/T30/30m/50m = 独立した加速profile材料
- 両者を恣意的な50:50平均にはしない
- 誤差分散または同時T90観測が取れてから統合する

## 次チャットで最優先にやること

**同一人物・同一試技で30mと50mが両方ある標準化データを増やす。**

特に2026年6月の大学代表選考で、31人全員を同じ光電管で50m＋途中30m測定している。全結果を取得できれば：
1. 30m↔50mの直接関係を数十人で較正
2. 50mから加速profileをより直接的に推定
3. 最高速度と30mの2軸からT90統合モデル候補を作る
4. PowerProを見ずに凍結
5. 99人QAで改善するか確認

これが次の一手。
