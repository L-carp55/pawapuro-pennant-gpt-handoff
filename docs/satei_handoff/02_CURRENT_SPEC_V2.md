# パワプロ野手査定仕様 v2.0（現行ドラフト）

状態ラベル:

- **ADOPTED**: 現在の正式ルール
- **PROVISIONAL**: 方向性は採用、係数未校正
- **REJECTED**: 使用禁止
- **OPEN**: 未決定

---

## 1. 目的と対象

### 1.1 目的

実在野手を、現実成績・時代・リーグ・球場・出場量・得能を考慮し、パワプロ風に再現する。

目的はKONAMI能力のコピーではない。KONAMI査定は後段の比較対象とする。

### 1.2 対象

- NPB現役・過去選手
- MLB選手
- 戦前・短縮シーズン
- 単年ピークカード
- 全盛期合成カード
- 2015年以降KONAMI実装との比較

投手は別仕様。野手v2.0で投手を査定してはならない。

---

## 2. 4層分離 — ADOPTED

```text
補正成績
= 年度・リーグ・球場・サンプルを補正した統計

平均得能込み基準
= 同じ補正成績帯の平均的な得能を含む能力

個別査定能力
= 当該選手に付ける得能との差を反映した基礎能力

実効能力
= ゲーム内で基礎能力と得能を合成した性能
```

能力表には、どの層の数値かを必ず明記する。

---

## 3. カード種別 — ADOPTED

### 3.1 ピーク単年カード

- 一つの年度のみをラベルにする。
- 周辺年度はPriorと信頼度にのみ使う。
- 別年度の長所を直接合成しない。

### 3.2 全盛期合成カード

- 複数年を明示的に合成する。
- 単一年のラベルを付けない。
- 合成式と対象期間を公開する。
- 旧 `0.50 Best3 + 0.30 Best1 + 0.20 Best5` は未校正のためREJECTED。

### 3.3 2017 WBC案件

「各選手の全盛期」の意味が未確定。

推奨:

1. まずピーク単年カードを作る。
2. 必要なら別成果物として全盛期合成カードを作る。

両者を混ぜない。

---

## 4. 基準環境 — ADOPTED

基準年は2019年NPB。

理由:

- 143試合制
- 現代に近い
- 極端な打低・短縮年を避ける
- パワプロ現代査定との比較に向く

環境補正では、選手統計とリーグ平均の**文脈を一致**させる。

例:

```text
選手がAVG_vsR_nonRISPなら、
リーグ平均もAVG_vsR_nonRISPを使う。
```

総打率リーグ平均と分割打率を混ぜない。

## 5. ミート — ADOPTED / PROVISIONAL

### 5.1 基準統計

理想:

```text
AVG_neutral_raw = AVG_vsR_nonRISP
```

データ階層:

| 階層 | 入力 | 処理 |
|---|---|---|
| A | 対右×非得点圏のH/AB | 直接使用 |
| B | 対右、対左、RISP、non-RISPの周辺値 | 対右を暫定基準。交差値を捏造しない |
| C | 総合のみ | 総打率を暫定使用し、信頼度を下げる |

REJECTED:

```text
AVG_vsR - 0.30 × (AVG_RISP - AVG_nonRISP)
```

周辺集計だけでは交差セルを一意に求められない。

### 5.2 小サンプル

経験ベイズ型へ縮小する。

```text
AVG_post
= (H_context + kappa_M × AVG_prior)
  / (AB_context + kappa_M)
```

- `AVG_prior`: 本人周辺年度、リーグ平均、二軍/MLB変換等
- `kappa_M`: 校正対象
- ケガ、限定起用、新人等はPrior選択へ反映

### 5.3 平均得能込みミート

補正後打率から連続関数で変換する。

旧目安:

| AVG* | ランク |
|---:|---|
| 〜.180前後 | G領域 |
| .180〜.230 | F |
| .230〜.260 | E |
| .260〜.280 | D |
| .280〜.320 | C |
| .320〜.340 | B |
| .340〜.365 | A |
| .365以上 | S |

注意:

- 境界の重なりをなくす。
- 数値への変換関数は今後校正する。
- 「.300→M65」等はアンカー。最終関数はまだPROVISIONAL。

### 5.4 得能調整

方向:

```text
青得能が同成績帯平均より多い → 基礎Mを下げる
赤得能が多い → 基礎Mを上げる
三振赤特 → 少しだけ上げる
高パワー → 同打率ならMを少し下げる
低パワー → 同打率ならMを少し上げる
内野安打・俊足BABIP → 一部を走力/内野安打○へ分離
```

具体点数はOPEN。ゲーム内シミュレーションで校正する。

### 5.5 二重計上禁止

完全な`AVG_vsR_nonRISP`を使った後に、チャンスB・対左Bを理由にさらにMを下げない。

調整台帳に、各要素がどこへ入ったかを記録する。

## 6. パワー — ADOPTED / PROVISIONAL

### 6.1 500PA相当本塁打

2019年NPBの500PA以上打者から、

```text
ABref_500PA = 約436.25
```

現行式:

```text
HR_500PAeq_raw
= HR / AB × 436.25
```

`HR500AB`は使用禁止。

### 6.2 環境補正

```text
HR_500PAeq_env
= HR_500PAeq_raw
× EnvironmentFactor
× ParkFactor
× LeagueFactor
```

`EnvironmentFactor`は、対象年と2019年の同じ定義のHR率から推定する。

旧 `gamma_HR=0.45〜0.60` は未校正のためPROVISIONAL。

### 6.3 小サンプル

```text
HR_rate_post
= (HR + kappa_P × HR_rate_prior)
  / (AB + kappa_P)
```

```text
HR_500PAeq_post
= HR_rate_post × 436.25
```

固定ShortRoleDragはREJECTED。

### 6.4 補助指標

- ISO
- SLG
- 2B/3B
- Barrel%
- Hard-Hit%
- EV/Max EV
- xSLG
- HR/FB
- FB%
- Launch Angle
- Park Factor

本塁打だけで決めない。ただし2B/3Bの脚力寄与をパワーへ過剰に入れない。

### 6.5 平均得能込みパワー

旧アンカー:

| HR_500PAeq* | P目安 |
|---:|---:|
| 10 | 60 |
| 20 | 70 |
| 30 | 80 |
| 40 | 86〜87 |
| 46 | 90 |
| 56 | 100 |

これらは平均得能込み基準。

最終変換は連続関数へ実装し、重複境界をなくす。

### 6.6 現代NPB野手のパワーG

「一軍野手だから下限」とはしない。

一方、2015年以降のKONAMI実装で野手P-Gがほぼ使われないという校正情報は別管理する。

暫定:

```text
現代NPB野手のP<20/Gは例外扱い
P-F下位を優先
```

歴史選手、特殊カード、投手には自動適用しない。

## 8. 少打席・ケガ・起用 — ADOPTED

### 8.1 少打席は常に減点ではない

少打席は推定値の不確実性を大きくする。結果をPriorへ回帰する。

### 8.2 ケガ離脱型

例: 柳田、近藤、オースティン型。

- 周辺年の本人実績を強いPriorにする。
- 出場中の打球内容が維持されていれば能力を大きく落とさない。
- 稼働率はケガしにくさへ。

### 8.3 限定起用・左右併用

- 対戦相手選択バイアスを考える。
- 対右・対左別で評価。
- リーグ平均や周辺年へ強く回帰。

### 8.4 新人・ブレイク初年度

- 二軍・前年・同タイプPrior。
- 単年上振れを満額評価しない。

---

## 9. 疲労補正 — OPEN / PAUSED

旧固定式は停止。

理由:

- 出場量は能力、健康、起用、疲労、不調継続を同時に含む。
- 単純加点は耐久性を打撃能力へ二重計上する。

再導入には同一選手の月別・連戦・休養後データ等による実証が必要。

---

## 10. 走力・盗塁 — ADOPTED

詳細は`04_RUNNING_DEFENSE_CATCHER.md`。

要点:

```text
走力 ≠ 盗塁数
```

走力は純粋速度を測る。盗塁は技術・判断・企図を得能にする。

---

## 11. 守備・捕球・肩・送球 — ADOPTED / PROVISIONAL

詳細は`04_RUNNING_DEFENSE_CATCHER.md`。

正式ルール:

- エラーは捕球。
- 送球エラーは送球得能。
- 守備力は範囲・反応・判断。
- GG賞を使わない。
- 出場量は信頼度へ。自動加点しない。
- 外野は走力が高いほど、同範囲なら守備力を低くする。
- 内野の走力補正は小さい。

係数は未校正。

---

## 12. 捕手 — ADOPTED / PROVISIONAL

盗塁阻止へのゲーム内寄与順:

```text
肩 > 送球 > 守備力
```

係数未校正。

捕球は盗塁阻止と分離し、失策・捕逸等で査定。

---

## 13. 得能 — ADOPTED / PROVISIONAL

- 得能は実成績を分解するもの。
- 平均得能込み能力から、当該選手の得能量との差を基礎能力へ反映。
- 点数寄与は未校正。
- チャンス・対左は単年ブレを多年度へ回帰。
- RBIをチャンスへ直接使わない。
- 金特は歴史的水準のみ。

---

## 14. KONAMI比較 — ADOPTED

1. 独自査定を先に確定。
2. ファイルハッシュまたはコミットで凍結。
3. KONAMI能力を読み込む。
4. 作品・更新日・対象期間を一致。
5. 基礎値、得能、適性、ケガ、調子を比較。
6. 実効能力の差を説明。
