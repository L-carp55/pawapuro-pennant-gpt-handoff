### 使わない（理由つき）

- **キャラクター性の得能**（サヨナラ男・お祭り男・夏男・春男・秋男・逆境○・威圧感・存在感）
  … 実成績から逆算できない。少ない標本の偶然を能力として固定することになる
- **対戦相手別のキラー系**（巨人キラー等12種）… 同上。年度で入れ替わる
- **打撃フォーム系**（プルヒッター・流し打ち・広角打法・ラインドライブ・意外性）
  … 打球方向のデータ（2023-2025のみ）があれば作れる。**保留**
- **投手用**（安定度・回復の一部）… 野手の査定の対象外

## 3. ★走塁と走力の分離（今回の指摘の本題）

### 仕様が定めていること

仕様04 §1.2 は**走力**の第3階層（補助）に、
`三塁打率 / 内野安打率 / 併殺回避 / BsR・UBR / 追加進塁率` を挙げ、こう注意している:

> 三塁打には球場形状、打球方向、長打力が混ざる。

仕様04 §3 は**走塁得能**に、
`一塁から三塁 / 二塁から本塁 / タッチアップ / 追加進塁 / 走塁死 / BsR・UBR / 三塁打のうち速度寄与` を挙げる。

**同じ材料が両方に出てくるが、二重計上ではない。** 構造はこうなっている:

- 走力 … その材料から「脚の速さ」を推定する
- 走塁得能 … 同じ材料から、**走力で説明できる分を引いた残差**を取る
  （＝「その脚力の割に上手いか」。現行の `baserunningAbility` がこの形）

オーナーの例で言えば、走力E走塁Aの選手は、脚は遅いのに三塁到達が速い。
これは「脚力から期待される到達時間」より速い＝残差が大きい、として表れる。

### いまの実装の状態と、足りないこと

| | 走力（脚力） | 走塁得能（残差） |
|---|---|---|
| 三塁打の割合 | ✅ 使用中（重み0.695） | ❌ 未使用 |
| 併殺回避 | ✅ 使用中（0.620） | — |
| 内野安打率 | ✅ 使用中（0.586） | — |
| **自作の走塁指標** | ✅ 2026-08-05追加（0.533） | ❌ **未使用** |
| UBR | ✅ 使用中（0.445） | ✅ 使用中 |

**足りないこと（今回の指摘で判明）**:

1. **自作の走塁指標（一塁→三塁など22,459件）が走塁得能に使われていない。**
   仕様04 §3 が名指ししている材料そのものなのに、走力側にしか入れていなかった。
   走塁得能は現在UBRの残差だけで作っている。
2. **三塁打の割合に走塁能力が混ざっている。**
   仕様も「球場形状・打球方向・長打力が混ざる」と注意しているが、
   オーナー指摘の通り**走塁の上手さ**も混ざる。重み0.695で最も重く効かせているので影響が大きい。

### 次にやること

- 自作の走塁指標を**走塁得能の材料にも加える**（走力に対する残差として。二重計上にならない）
- 三塁打の割合から走塁の寄与を分離できるか測る
  （自作の走塁指標を持つ選手で、三塁打割合のうち走塁で説明できる分を見る）

## 4. 記録

- 得能の実数は `scripts/` から機械的に数えた（手で数えない）
- 「使わない」と決めたものは理由を残す。後で「なぜ入れていないのか」を再検討できるように
- パワプロの得能そのものは**採否の物差しにしない**（2026-07-31オーナー確定）。
  ここでは「ゲームにどういう軸があるか」の一覧としてのみ使う
