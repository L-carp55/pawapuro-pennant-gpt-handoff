# 走力と走塁技術の分離 — 外部検証メモ

日付: 2026-08-07
用途: モデル学習ではなく、定義・sanity・時間規律の独立検証。

## 1. ぱわらぼ「走力を再考する」の扱い

記事:
`https://pawapuro-lab.com/entry/evaluation_running`

重要な時間規律:
- 記事本文は、NPB+のトラッキングデータが2025年に収集・2025年10月に公開されたと説明している。
- そのうえで「能力値が確定している2024年の規定打席到達打者」の成績・パワプロ能力と、NPB+ Sprint/H1を横に並べている。
- よって表のSprint/H1を**2024年本人の直接計測としてカードへ入れてはいけない**。2024成績に2025 trackingを組み合わせた分析表として扱う。

一方、speed/skill分離の外部検証としては有用。

記事表の例:

```text
周東  Sprint 35.2 km/h / H1 3.45 s
近本  Sprint 33.5 km/h / H1 3.94 s
源田  Sprint 33.4 km/h / H1 3.84 s
```

Sprintだけなら近本と源田はほぼ同等で近本が0.1km/h上。
H1では源田が0.10秒速い。
これは「H1の差 = 純粋速度の差」ではないことと整合する。

さらに同じSprint 33.5 km/hでも:

```text
中野  H1 3.72
近本  H1 3.94
森下  H1 4.35
```

と大きく差がある。
したがってH1には最高速度以外の成分が非常に大きい。

## 2. DELTA 2018一塁到達分析

記事:
`https://1point02.jp/op/gnav/column/bs/column.aspx?cid=53493`

2018年の三塁ゴロについて:
- 打者走者の一塁到達時間
- 打球のハングタイム

を組み合わせて内野安打確率を分析している。
4.00秒未満の一塁到達が内野安打の増える目安になり、4.00秒未満を11回以上記録した選手を別表にしている。

この資料が示すこと:
- 野球中の実走時間を使う価値は高い。
- ただしH1は「内野安打を作るための結果変数」であり、純粋速度だけではない。
- 打球ハングタイムとの共同モデルにしないと、内野安打skillとspeedを分離できない。

## 3. プロジェクト既収集の非打席タイム

`web_collected_measurements.json` には:

```text
近本光司 2019
一塁→二塁 3.1秒
甲子園・投手不在の走塁練習
筒井外野守備走塁コーチがストップウォッチ計測
```

が保存済み。

これは打席離脱を含まない点でH1より身体的走能力へ近い証拠。
ただし1選手1観測だけなので、全選手共通モデルの係数には使わない。
近本個人を手動で上げる教師ラベルにもせず、独立evidenceとして保持する。

## 4. 現在の結論

- 走力は50m走そのものではない。
- Sprint Speedは純粋走力の最高速度側の直接アンカーとして最も強い。
- MLB 5→30ft splitは最高速度とは別の身体的加速軸として直接測れる。
- H1は野球特有の重要な実走指標だが、打席離脱・走り出し・駆け抜け等が大きく混ざるので純粋走力へ丸ごと入れない。
- 近本と源田のような近い純粋速度を、内野安打/UBR/GDP集約だけで無理に順位付けしない。
- 直接証拠が足りない年度は、不確かな推定値を確定能力として出すより未査定を維持する。
