作成日: 2026-08-12
本体: `speed_rebuild_independent_red_team_20260812.md` R-4 の裏取り

## 検証

`outputs/derived/speed_2026_100_master_evidence.csv` の
`blind_v3_baseline_rating` を `npb_plus_sprint_speed_kmh` へ単回帰した結果:

```text
rating = -218.0884 + 8.9752 × NPB+速度(km/h)
n = 99
相関 r = 1.000000
決定係数 R² = 1.000000
最大残差 = 0.000544 点
```

**99人全員が、この直線の上に誤差0.0005点で乗っている。**

## 意味

差分handoffは「NPB+最高速度中心へ戻ってしまった」と自己評価しているが、
実際には **"中心" ではなく "それだけ"** である。

出力に一切効いていないもの:

- physical evidence ledger 459件
- high-confidence anchor 113件
- pairwise graph 200本
- Grok-X SNS 41採用
- video tie-break
- exposure audit
- PowerPro long panel

唯一の例外は最終freezeで手動修正されたモンテロ1件（68→52）のみ。

## 実測との矛盾（同じ計測値で15点差）

| 選手 | 直接計測 T90 | baseline rating |
|---|---|---|
| モンテロ | **4.20秒**（2024） | **68.2** |
| 筒香 嘉智 | **4.20秒**（2022） | **53.0** |
| 秋山 翔吾 | **3.97秒**（2021・モンテロより速い） | **65.5** |

同一の計測値で15点差が生じ、より速い選手の方が低い。
物理実測が点数へ接続されていないことの直接的な証拠。

## 感度

```text
NPB+速度 0.1 km/h の差 = 0.90 点
観測レンジ = 29.0 〜 35.0 km/h（6.0 km/h で54点）
```

NPB+の報告粒度が0.1km/hなので、**量子化だけで±0.45点**。
測定ノイズ0.5km/hなら**4.5点**動く。
Claude会話期のT-0107記録（レンジが狭く傾きが誤差を約7倍に増幅、
矢野雅哉が60打席の実測で-24.9点動いた）と整合する。

## 結論

R-4 は推定ではなく**確定**。NPB+単独を軸に据える設計は、
集めた証拠を構造的に捨てる。アンカー導入（裁定2026-08-12①）で置き換える。
