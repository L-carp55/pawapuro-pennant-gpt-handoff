# 走力の「材料が割れている」の正体 — 診断

作成日: 2026-08-13
きっかけ: オーナーレビュー表の1段目に「こちらの材料が割れている」が多数出たため
（村林38点差・古賀優大37点・モンテロ31点・細川30点）。レビュー前に原因を特定した。

## 結論

**選手個別の食い違いではなく、2つの材料の目盛りが系統的にずれているだけだった。**

```text
NPB+実測由来 − プレー結果由来 の平均 = +14.4点
向きが同じ選手 = 93 / 97人
```

93/97が同方向なので、これは「この選手の評価が割れている」ではなく
**「NPB+由来の値が全員まとめて約14点高い」**という目盛りの問題。
パワプロとの比較で見つかった幅のずれ（1.67倍）と同じ病気が、
**こちらの内部の2材料の間にも起きていた。**

## 検証した仮説

| 仮説 | 結果 | 判定 |
|---|---|---|
| A. 出場が少ないほど食い違う（NPB+の観測不足） | 打席数 vs 食い違い r = **+0.347** | **不成立**。向きが逆（出場が多いほど食い違いが大きい） |
| B. 食い違いに系統的な向きがある | 平均 **+14.4点** / 93対4 | **成立**。これが主因 |
| C. どちらがより当たっているか | 下記 | プレー結果由来が上 |

## C の中身（順位の一致・目盛りの影響を除いた比較）

```text
プレー結果由来 vs パワプロ2026   r = 0.831
NPB+由来       vs パワプロ2026   r = 0.762
混合後         vs パワプロ2026   r = 0.825   ← 混ぜると少し下がる
```

**プレー結果の統計モデル単独が最も一致し、NPB+を混ぜると悪化する。**

現在 `blendDirect` はNPB+ top_speed に重み **0.762**（ホールドアウト test_r）を与えているが、
そのホールドアウトは **n=14** で、同じモデルの **test_mae は 10.55点**。
red-team の R-4（NPB+を主軸にすると誤差が増幅する）が、97人で裏付けられた形。

## ただし、この結果で重み付けを決めてはいけない

上の比較は**パワプロを物差しにしている**。2026-07-31オーナー確定で
パワプロは参考チェックへ格下げされており、**採否の物差しに使うのは違反**
（メモリ `feedback_reference_check_is_not_an_acceptance_criterion`）。

したがって本診断は「NPB+の重みは要見直し」という**疑いの提示まで**とする。
正式な判定は red-team 設計 §8 の一次指標で行う:

1. **時間ホールドアウト** — 2021-2024の材料で査定を作り、2025の実プレー結果
   （三塁打割合・内野安打率・進塁成功・GIDP回避）をどちらがよく予測するか
2. **エンジン整合** — リーグ全体を回して盗塁・三塁打・内野安打の分布が実データと合うか

## レビューへの含意

1段目に並ぶ「材料が割れている」型（村林・古賀優大・モンテロ・細川・郡司ほか）は、
**その選手固有の問題ではない**。オーナーが1人ずつ判断する必要は薄く、
**材料の目盛りを揃えれば大半が解消する**見込み。

→ レビュー時はこの型を後回しにし、
「パワプロ側の据え置き疑い」型（古賀優大9.2年・細川9.2年・岸田8.2年・村林7.2年・今宮6.7年）と
「出場が少なく観測不足」型（カリステ26試合・野間35試合）を優先していただくのが効率的。
