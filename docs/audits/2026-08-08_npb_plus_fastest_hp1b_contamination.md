# NPB+「最速一塁到達」のバント汚染検証

日付: 2026-08-08  
結論: **最速一塁到達は基礎走力/T90の直接アンカーに使わない。実測でバント利用の影響が検出された。**

## 1. きっかけ

オーナー指摘:

> 最速一塁到達タイムはセーフティバントがあるのとないのとで0.何秒か変わる。

個別例として周東佑京2024では、手元収集記録に

- 通常スイングの内野安打: 3.75秒
- セーフティバント: 3.40秒

があり、0.35秒差だった。

そこで「最速一塁到達」にバントの利用頻度がリーグ横断で混ざっているかをNPB+データで検証した。

## 2. データ

### NPB+ 2026途中

`npb_plus_measurement`:

- `top_speed_kmh`
- `hp_to_1b_sec`（最速タイム・一塁到達）

2025年NF3の打席左右 (`bats`) と突合できた99人を使用。

### バント利用

2025年 `v_batting` の犠打数 `SH` / 打席 `PA` を使用。

2026途中の最速タイムに2025年犠打率を当てるため完全な同年比較ではないが、
「バントを使うタイプの選手か」という傾向のproxyとして使用した。

## 3. まず最高速度と左右打席を統制

回帰:

```text
hp_to_1b_fastest
= 8.866731
- 0.144841 × top_speed_kmh
- 0.218795 × LHH
```

結果:

- n = 99
- top speed vs hp1b raw correlation = **-0.7389**
- R² = **0.7005**
- residual SD = **0.1496秒**
- 左打者効果 = **約-0.219秒**

ここで

```text
residual = 実際の最速一塁到達 - 上式の予測値
```

とした。

負の残差 = 最高速度と左右打席から予想されるより一塁到達だけが速い。

## 4. 残差と犠打率

2025犠打率と残差のSpearman相関:

```text
r = -0.3742
p = 0.000238
```

**犠打率が高い選手ほど、最高速度・左右打席から予測されるより「最速一塁到達」だけが速い。**

### 層別

- 犠打率上位25%: residual平均 **-0.0587秒**
- 犠打0の層: residual平均 **+0.0598秒**
- 差: **約0.1185秒**
- Welch t-test: **p = 0.00117**

つまりバントを多用する層は、身体速度を揃えても「最速一塁到達」が約0.12秒短い。

## 5. 犠打率を回帰へ直接追加

```text
hp_to_1b_fastest
= 8.611765
- 0.136232 × top_speed_kmh
- 0.207679 × LHH
- 2.175087 × SH_rate
```

結果:

- R²: **0.7005 → 0.7340**
- SH_rate係数 p = **0.00533**
- residual SD: **0.1496 → 0.1369秒**

犠打率が説明力を有意に追加した。

## 6. 解釈

これは「犠打そのものが脚を速くする」という意味ではない。

NPB+の掲載値が**シーズン中の最速一塁到達**なので、セーフティ/プッシュバント等で

- 接触前から走行姿勢へ移りやすい
- 接触後の最初の一歩が通常スイングと違う
- 最速値が1回の特殊プレーに引っ張られる

という文脈差を拾うためと考えるのが自然。

また、犠打率はセーフティバント率そのものではないため、効果を完全には分離できない。
それでも有意な関連が出たことは、最速一塁到達を身体的走力と同一視してはいけない強い証拠。

## 7. 正式判断

### 採用

- `hp_to_1b_fastest` は**T90/走力の直接アンカーとして使用禁止**。
- 通常スイング・計測条件が確認できるイベント単位の値だけTier CのQA材料に残す。
- シーズン平均home-to-firstも、左右打席とswing-to-run transitionが混ざるためTier C。

### 禁止

- NPB+最速一塁到達をそのまま走力へ変換
- 最高速度と最速一塁到達を単純平均
- バントと通常打撃を同一母集団で較正

## 8. T90設計との関係

この検証は、走力の中心尺度を

> **最初の走行ステップから90ftを走る身体的時間=T90**

にする判断を支持する。

T90では「バットに当たった瞬間→走り出すまで」の技術差を能力定義から切り離す。

盗塁のスタート判断やベースランニング技術も別得能へ残すため、
「野球で使える身体速度」と「走塁/盗塁技術」の二重計上を避けられる。
