## 2. 「十分」の閾値を同時点の標本誤差から決める

翌年再現性は使えないので、**1シーズン内の標本誤差**から決める。

```text
reliability = 1 − E[標本誤差の分散] / 観測された選手間分散
```
| 打席数 | n | 同時点の信頼性 |
|---|---|---|
| 50–100 | 270 | 0.60 |
| 100–150 | 174 | 0.71 |
| 150–200 | 132 | 0.66 |
| 200–300 | 171 | 0.70 |
| 300–400 | 133 | 0.78 |
| 400–500 | 153 | 0.80 |
| 500– | 141 | 0.84 |

信頼性が0.5（標本誤差＜選手間のばらつき）を最初に超えるのは **50打席**。
これを「current-yearだけで足りる」の閾値にする。

## 4. historical prior を使ってよい条件（明文化）

current-yearが十分でない時だけ過去年を足す。理由と重みを必ず記録する。

| 条件 | 記録する理由コード |
|---|---|
| その年の観測が閾値（50打席）未満 | `LOW_SAMPLE_CURRENT_YEAR(実測<閾値)` |
| その年の観測が無い | `NO_CURRENT_YEAR_OBSERVATION` |
| 十分に観測されている | `CURRENT_YEAR_SUFFICIENT`（＝過去年を使わない） |
| 従来どおりの自動プール | `LEGACY_AUTO_POOL`（現在の既定。移行までの対照） |

※ 故障・明らかな下振れ・明示的なtemporal bridgingは、**現状のデータでは自動判定できない**
（年齢・生年月日・故障情報が既存成果に存在しない＝SP-044 / SP-045 が BLOCKED_MISSING_DATA）。
そのため現時点で実装したのは打席数による条件のみで、残りは依存待ちとして明示する。
