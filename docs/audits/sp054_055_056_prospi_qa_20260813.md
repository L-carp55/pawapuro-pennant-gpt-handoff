## ★ Opus senior review 訂正（2026-08-14）

### 1. 「指紋の完全重複は 0」は誤りだった

同ディレクトリの `outputs/derived/sp054_055_prospi_run3_qa_20260813.json` は
`historical_detail.findings` に **`P-01 severity=MAJOR exact duplicate fingerprints: 1`**
を記録しており、本mdの記述と矛盾していた。

**実データで確認した重複の実体**:

| 項目 | 値 |
|---|---|
| fingerprint | `6497cec9aba53548` |
| 選手 | 小園 海斗 |
| edition | 2025 Series 2 |
| card type | **スペシャルセレクション** |
| 走力 | 79 |
| source_row_number | **145 と 146**（GameXページ内で同内容が二重掲載） |
| collected_at | 両行とも同一 |
| record_id | 片方に `-DUP02` サフィックス |

→ 収集側は**重複と認識しながら両方を出力**していた。取得時刻の差による別指紋、
といった定義上のすれ違いではなく、**mdの記述が単に事実と異なっていた**。
source of truth は QA JSON が正しい。

**訂正措置**: `-DUP02` 行の `acquisition_status` を `DUPLICATE_SUPERSEDED` へ変更。
**行は削除していない**（CLAUDE.md「rawは上書きせず」）。採用対象内の完全重複は 0 件になった。

### 2. special card の扱い

current 17件 = regular 14 + special/boosted 3。
**special を通常査定と同格の coverage として数えない**。SP-056 側は
`special_cards_excluded: true` が実際に効いており、小園のpairも「レギュラー」値78
（重複したspecialの79ではない）を使っていた——この点は APPROVE。
