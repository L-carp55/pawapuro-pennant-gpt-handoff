## 判定

### 結論: `NOT_IDENTIFIABLE`（現在のデータでは判定できない）

**現在のデータでは rolling holdout による NPB+ blend の採否を決められない。**

理由:

- 統計側は T-0198 の修理で `maxSeason = Y-1` へ**正しく制限できる**
- だが **NPB+ には過去年の snapshot が無い**。2026年に1回測った値しか存在せず、
  同じ時点へ制限することが**原理的にできない**
- したがって NPB+ を含む方式と含まない方式を同じ土俵で比べられない

この非対称を消す方法は現在のデータには無い。**判定は保留する。**

### 正式な control（漏れなし。以後の比較の基準線）

```text
統計モデル単独（maxSeason=Y-1、漏れなし）   平均r +0.405
  誤差(z単位) 0.804   有効セル 20
```
これが**唯一、予測年以降の情報を含まない数字**であり、正式なcontrolとして保存する。
NPB+を含む方式（現行blend・NPB+単独）はこのcontrolと**同じ土俵にない**ため、
数値を並べても優劣の判定にはならない。

### 参考diagnostic（★採否の根拠に使わない）

以下は「未来情報を同程度与えるとどうなるか」を見るための診断であり、
**validation / acceptance criterion から外す**（2026-08-13 オーナー指示）。
`statOpen`＝統計側にも窓制限を掛けない版で、**予測年以降の情報を含む**。

```text
統計・窓制限なし(diagnostic)          +0.599
窓制限なし+NPB+blend(diagnostic)     +0.512
セル単位 15勝 2敗 3分
```
★この 2 数値と勝敗は **(c) 採用の根拠にしてはならない**。両側とも漏れている。

以前この文書は同じ比較をもって「現行NPB+ blendは一貫した悪化要因」と結論していたが、
**撤回した**。限界節に「両側に窓の緩みがある」と書きながら、その比較を結論に使っていた。
