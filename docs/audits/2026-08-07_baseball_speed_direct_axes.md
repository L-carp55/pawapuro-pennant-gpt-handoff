# 野球走力: 最高速度と一塁到達を別観測にする監査

日付: 2026-08-07
結論: **最高走行速度は純粋走力の直接アンカー候補。一塁到達の独自差は走力へ即統合しない。**

再現: `scripts/audit_baseball_speed_direct_axes.mjs`
GitHub Actions: `31175508932`

## 背景

オーナー確定:

- 走力と内野安打○・走塁・盗塁等の技術を完全分離する。
- 走力は50m走タイムそのものではなく、野球で発揮される脚の速さ。

このため、直接計測も単一値へすぐ潰さず、何を測っているか分けて確認した。

## 1. NPB+ 2026

最高走行速度と一塁到達時間の両方を持つ100人。
打席左右まで結合できた99人。

```text
最高走行速度 vs 一塁到達時間 r = -0.739
```

かなり強い共通信号がある。

### 左右打席

```text
右打者 n=44
平均一塁到達 4.322秒
平均最高速度 31.35 km/h
両者 r=-0.633

左打者 n=55
平均一塁到達 4.052秒
平均最高速度 31.78 km/h
両者 r=-0.853
```

左打者は一塁に物理的に近く、打席の出方も違うため、一塁到達をそのまま走力にはできない。

## 2. MLB複数年での安定性

MLB bridgeの年別Sprint Speed / home-to-firstを使用。

```text
Sprint Speed 翌年一致
179ペア r=0.932

home-to-first 翌年一致
143ペア r=0.944
```

どちらも非常に安定した個人特性を含む。

さらに:

```text
home-to-first
~ Sprint Speed + 年度
```

で期待値を作り、残差を年ごとに算出。

```text
H1残差 翌年一致
143ペア r=0.868
```

つまり「最高速度が同じでも一塁到達が速い/遅い」という差は偶然ではなく、かなり安定した個人差。

ただし、これを直ちに身体的な`加速力`と呼んではいけない。

混ざり得るもの:

- 本当の初速・短距離加速
- スイングから走り始めるまでの動作
- 打席からの出方
- 一塁へのライン取り/駆け抜け
- 全力疾走の選択

## 3. NPBの野球結果との関係

NPB+直接計測と2023-2025の結果を98人で対応。

| 結果 | 最高速度とのr | 最高速度から期待されるより速いH1残差とのr |
|---|---:|---:|
| 内野安打/in-play | +0.660 | +0.250 |
| 併殺回避 | +0.582 | +0.111 |
| UBR/PA | +0.619 | -0.010 |
| 盗塁企図 | +0.694 | +0.209 |
| 盗塁成功率 | +0.284 | -0.010 |

### 解釈

最高速度は:

- 内野安打
- UBR
- 併殺回避
- 盗塁企図

へ幅広く共通して乗っている。

一方、H1独自残差は:

- 内野安打へ弱く乗る
- 盗塁企図へ弱く乗る
- UBRにはほぼ乗らない
- 盗塁成功率にはほぼ乗らない

したがって、H1独自差をすべて「野球上の走力」に入れると、打席固有技術を身体能力へ混ぜる危険が高い。

## 4. 現在のモデル判断

### 最高速度

**純粋走力の第1アンカー候補として残す。**

ただし最終走力 = 最高速度だけ、と確定したわけではない。
走力には短距離加速も含めたいので、追加の識別が必要。

### 一塁到達時間

そのまま走力へ入れない。

### H1残差

内部的に:

```text
batter-box / short-run unresolved axis
```

として隔離する。

身体的加速だと確認できた成分だけ将来baseball speedへ移し、残りは内野安打系/打席離脱系の得能へ置く。

## 5. 次の識別問題

必要なのは「打席を介さない短距離加速」の情報。

候補:

1. 走者としての短距離split-timeの直接データ。
2. 盗塁・追加進塁等のイベントで、判断/相手条件を統制した後に複数種類の非打席走へ共通して残る選手因子。
3. MLB/NPBの別トラッキングデータに加速度・splitがあれば直接使用。

これが無ければ、無理にH1残差を身体能力へ入れず未分離を維持する。

## 6. 本番への影響

- 走力: 未査定
