# 内野肩 proxy 研究 round 2

日付: 2026-08-07
結論: **まだ本番未採用。候補は「文脈調整した複数年の深部アウト残差」だけ残す。**

## 背景

棄却済み:
- 守備位置から肩を推定: 外部照合でほぼ無相関
- NPB+平均送球速度: 内野では送球距離・プレー要求の影響が強く、位置内補正でも不合格

アウト/内野安打/悪送球/その他失敗、処理位置座標、打者、野手、守備位置を保持する。

## 候補B: 深さへの耐性 slope

仮説:
肩が強いなら、通常位置での上手さではなく「深くなるほどアウト率が落ちにくい」という傾きに現れるはず。

捕球位置(hc_x/hc_y)、打者速度proxy、年度で全体アウト確率をlogistic回帰し、イベント残差を作成。
野手ごとに `residual ~ depth` の傾きを肩proxyにした。

結果:

```text
DELTA外部評価との相関
min80件  n=5 r=-0.420
min100件 n=5 r=-0.420
min150件 n=4 r=-0.581
min200件 n=4 r=-0.581
```

隣接年再現性は raw より多少改善したが弱い:

```text
min30件 44ペア r=+0.147
min40件 33ペア r=+0.118
min50件 28ペア r=+0.186
min60件 24ペア r=+0.054
```

外部相関が逆方向なので**棄却**。

再現: `scripts/audit_infield_arm_depth_slope.mjs`
Actions: `31160246522`

## 候補C: 文脈調整した深部残差を複数年pool

深さの傾きではなく、深いプレーそのものについて:

```text
residual = actual_out - expected_out
```

を作り、その平均を複数年で束ねる。

`expected_out` は以下を全体データから推定:
- 捕球位置の深さ
- 横方向位置
- 非線形な位置項
- 打者速度proxy
- 年度

打者速度proxyはNPB+最高走行速度96人から作った3特徴（併殺回避・UBR/PA・内野安打/in-play）をnuisance調整にだけ使用。

### 外部DELTAとの一致

```text
deep20% external n=5 r=+0.347
deep25% external n=5 r=+0.578
deep30% external n=5 r=+0.578
deep35% external n=5 r=+0.592
deep40% external n=6 r=+0.612
deep50% external n=6 r=+0.688
```

### multi-year安定性

同じ選手のイベントを偶数年pool / 奇数年poolへ完全分離し、残差平均を比較。

代表値:

```text
deep25%, 各half20件以上: 16ペア r=+0.455
deep25%, 各half30件以上: 10ペア r=+0.391

deep35%, 各half30件以上: 13ペア r=+0.417

deep40%, 各half30件以上: 15ペア r=+0.337

deep50%, 各half30件以上: 16ペア r=+0.367
deep50%, 各half40件以上: 13ペア r=+0.356
```

raw単年率より明確に安定するが、肩力の確定に必要な水準かはまだ断定できない。

## 次に必要な検証

1. 外部直接ラベルを6人より増やす。NPB+平均送球速度は使わない。
2. 深部閾値20/25/…を外部6人に合わせて選ばない。独立holdoutまたは別の直接ラベルで固定する。
3. 1B/2B/3B/SSごとに捕球位置→送球距離の意味が違うため、位置別モデルを作る。
4. 捕球/持ち替え/送球精度をさらに分離する。悪送球TEは肩ではなく送球得能。
5. 対象年以前だけのmulti-year poolで過去年カードを作れることを確認する。

これらを満たすまでは `infield_arm_ability.enabled=false` を維持し、内野肩は未査定。
