# SP-016 final — 連続 historical prior の設計（hard 50PA gate を最終形にしない）

生成日: 2026-08-14
状態: **設計確定・検証済み。production適用は保留（下記§5の対の作業が要るため）**

## 1. 採用する形

```text
z_cur_shrunk  = z_cur  × PA_cur /(PA_cur  + κ)
z_hist_shrunk = z_hist × PA_hist/(PA_hist + κ)
z = (PA_cur·z_cur_shrunk + λ·PA_hist·z_hist_shrunk) / (PA_cur + λ·PA_hist)
κ = 50（SP-016 v1 が同時点信頼性から出した「信頼性0.5交差」を引き継ぐ）
λ = κ / median(PA_hist)   … 過去年を現在年の何割の精度として扱うか
```

**current-year中心のowner ruleは維持**——観測が増えるほど historical prior は連続的に弱まり、
十分な観測では実質 current-year のみになる。hard gate は κ を無限にした階段＝この形の退化形。

## 2. ★素朴な形は棄却した（実測で判明）

最初に検討した `w = PA/(PA+κ)` で `z = w·z_cur + (1−w)·z_hist` とする形は、
**current PA が極小のとき PA比例プールより現在年を過大評価する**。

実測: 東妻純平 PA=6 → w=0.107。PA比例なら約0.02。
6打席の極端な z が 10.7% 効き、**130点 → 71.3点（59点の振れ）**。

原因は **z_cur 自身を縮小せずに混ぜていた**こと。
→ 各推定を自身の信頼性で縮小してから精度で合成する階層縮小へ変更した。

## 4. 例外（故障・明らかな下振れ）の判定可能性 — 既存データでの実測

年齢・生年月日・故障データは存在しない（SP-044/045 BLOCKED_MISSING_DATA）。
既存データだけで何が判定できるかを 303人で実測した。

| 例外 | 検出数 | 判定 |
|---|---|---|
| **少出場** | 87人（<50PA） | **専用規則は不要**。連続版が w_cur を自動的に小さくして扱う |
| **出場の断絶**（前年200PA以上→当年30%未満） | 15人 | **検出はできるが自動適用しない**。故障・不振・起用方針の区別がつかない。フラグとして残す（例: 秋山翔吾 587→157、野村大樹 412→36、上川畑大悟 305→81） |
| **明らかな下振れ**（履歴分布から2SD外） | **79人／303人＝26%** | **この形では使えない**。2SD閾値なら期待5%程度のはずが26%発火。履歴年数が2〜3年しかなく履歴SDが小さすぎるため。**下振れ検出器としては不成立** |

**結論**: 既存データで自動適用してよい例外は **「少出場」だけ**で、それは
連続版が構造的に吸収するので**例外規則そのものが不要**になる。
故障・下振れは検出フラグに留め、**自動では historical を強めない**。

## 5. ★production適用を保留した理由（対の作業が要る）

連続版は 303人中 **85人を5点以上動かす**（hard gate比）。これは pooling の判断だけでなく
**全選手に縮小がかかる**ため。

ここで問題になるのが `applyScale`。現行の較正
（slope=1.3811 / intercept=−4.330）は **縮小していない現行値**に対して当てたもの。
縮小を入れると分布の幅が変わるので、**較正をやり直さないと目盛りがずれる**
（既存メモリ「モデルを直すと較正が無効になる。修正と較正のやり直しは常にセット」の型）。

- 較正のやり直し自体は SP-046 A-1（global display scale の provisional 参考）で**許可されている**
- ただし今回のオーナー指示は **SP-071（absolute scale finalization）を行わない**
- 85人が5点以上動く production 変更を、較正やり直しとセットで一度に入れるのは
  本waveのscope（architecture/methodology）を超える

→ **設計は確定・検証済みとして固定し、適用は「連続版＋applyScale再導出」をセットで行う
1つの作業として次工程へ渡す。** 部分適用（縮小だけ入れて較正を直さない）は**してはいけない**。
