# SP-016（続き）— 50打席hard gateを最終設計として凍結してよいか

生成日: 2026-08-13
状態: **50打席hard gateは working default。最終設計として凍結しない。** current-year-firstの方向性は維持

## 0. 何を問われたか（オーナー指摘 2026-08-13）

> current-year-firstという方向性は維持しますが、49/50PAで挙動が急変するhard gateが
> 最終設計として適切か確認してください。PAだけでなく、各componentの観測量・same-time
> reliabilityを使ったcontinuous historical-prior weightingとの比較も行い、50PAは現時点の
> working defaultとして明示してください。

## 1. 比較した4方式（いずれもowner ruleに反しない範囲）

| 方式 | 内容 |
|---|---|
| A `legacy` | 前後3年を観測量で加重平均。current-yearを特別扱いしない（旧production） |
| B `hard_gate_50` | current-year PA≧50なら単年のみ、未満なら全年pool（**現production既定**） |
| C `continuous_pa` | `w_cur = PA/(PA+κ)`, κ=50 でcurrent↔historicalを連続配分。**Bと同じ較正点を持つ不連続のない対応物** |
| D `continuous_component` | **材料ごと**にcurrent-year試行回数と同時点信頼性からw_curを決め、材料別に配分してから合成 |

Cのκ=50は恣意ではない——同時点信頼性が0.5を横切るのが50打席であり、経験ベイズ形 `w/(w+κ)` が
0.5になるのは `w=κ` のとき。BとCは同じ較正点を共有する。

Dの材料別κは実データから較正した:

| 材料 | 同時点信頼性 | 1シーズン中央試行数 | κ |
|---|---|---|---|
| 三塁打割合 | 0.496 | 14 | 14.2 |
| 併殺回避 | 0.433 | 106 | 139.0 |
| 内野安打率 | 0.533 | 237 | 207.5 |
| advance | 0.221 | 18 | 63.5 |
| UBR | 0.496 | 335 | 340.4 |

## 2. 不連続性は実在し、しかも大きい

**(a) 実際に跳んだ選手**: 閾値を49→51打席へ動かして査定が動いたのは **1人・1.6点**。
ただしこれは「今年たまたま打席数が境界にいた人数」であり、設計上の問題の大きさではない。

**(b) ★崖の高さ**（境界帯25-100打席の各選手で `|単年のみの値 − pool版の値|`）:

| 指標 | 値 |
|---|---|
| 対象 | 73人 |
| 平均 | **9.93点** |
| 最大 | 33.6点 |
| 10点以上 | **30人** |

**境界にいる選手は、打席数が1つ違うだけで平均約10点・最大33.6点の差を受けうる。**
連続版ならこの落差は0。**hard gateは最終設計として不適切**と判断してよい水準の不連続性がある。

## 4. ★construct validity（と、この基準を使ってはいけない範囲）

NPB+ sprint speedに対する相関（n=92）:

| 方式 | r | vs B の差 | CI95 |
|---|---|---|---|
| A `legacy` | **0.768** | +0.108 | [0.044, 0.193] 0を含まない |
| B `hard_gate_50` | **0.660** | — | — |
| C `continuous_pa` | 0.708 | +0.048 | [0.021, 0.077] 0を含まない |
| D `continuous_component` | **0.756** | +0.096 | [0.037, 0.176] 0を含まない |

**現production（B）が4方式中いちばん低い。** 3つの代替すべてがBを上回り、CIはいずれも0を含まない。

### ただしこの基準で「どれだけ過去年を混ぜるか」を決めてはいけない

NPB+ sprint speedは2026 snapshotの安定した集計量なので、**多年poolした推定ほどノイズが減って
機械的に相関が上がる**。この基準に最適化すると、

- 「相関が上がるから過去年をもっと混ぜよう」という結論が出る
- それは **EX-006で問題になったWRONG_VALIDATION_TARGETと同型の誤り**であり、
- 「年度査定はcurrent-year中心」というowner ruleを、相関最大化の名目で侵食する

実際、上表で最も相関が高いのは**current-yearを特別扱いしないlegacy（A）**である。
これを「Aが正しい」と読んではならない——選手が今年本当に遅くなった場合、単年値はそれを正しく
反映し、pool値は反映しない。だが多年集計の基準に対しては pool値の方が高く相関する。
**相関の高さは、この問いに関しては正しさの証拠ではない。**

したがってこの節から言えるのは次の一点に限る:

> **同じcurrent-year-first較正点(κ=50)を共有するBとCの比較で、不連続な形（B）より
> 連続な形（C）の方が良い**（+0.048、CI [0.021, 0.077]）。
> ＝**同じ方向性なら、hard gateよりcontinuousの方が良い形である**という、形についての示唆。

## 5. 結論

1. **50打席のhard gateは working default であり、最終設計として凍結しない**
2. current-year-firstの**方向性は維持**する（owner rule。相関を理由に緩めない）
3. 不連続性は実在し大きい（境界帯で平均9.93点の落差）。最終設計は**連続形が有力**
4. ただし最終形（C: PA一括 か D: 材料別 か、κをいくつにするか）の決定には、
   **多年poolに構造的に有利でない判定基準**が要る。現時点でそれは無い
5. 決着に必要なもの: SP-019第2版と同じ問題——**同時点の直接physical evidence**の
   coverage拡大（direct T90が現在n=2）。「今年その選手が実際どれだけ速かったか」を
   独立に測れて初めて、単年重視と多年poolのどちらが正しいかを判定できる
