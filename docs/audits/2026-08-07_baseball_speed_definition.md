# 野球上の走力と走塁技術の完全分離

日付: 2026-08-07
状態: **オーナー定義確定。旧proxy走力は本番停止。**

## オーナー判断

1. `走力` と `内野安打○ / 走塁 / 盗塁` 等の走塁系得能は完全に切り分ける。
2. 必要なら独自得能を追加してよい。結果指標を無理に走力へ押し込まない。
3. ただし `走力` は陸上の50m走タイムそのものではない。**野球で発揮される脚の速さ**を評価する。

## 1. 走力の定義

```text
走力 = 野球の直線走で発揮する潜在身体能力
```

含むもの:

- 静止〜低速状態からの初速
- ベース間に近い27〜30m程度での加速
- 競技中の最高走行速度
- その距離で速度を維持する能力

含めないもの:

- 投手の癖を読む
- 盗塁のスタート判断
- 打球判断
- ベースの回り方
- 曲線走の技術
- スライディング
- 一塁駆け抜けの技術
- スイング終了から走りへ移る効率

したがって公称50m走タイムをそのまま能力値へ変換しない。
50m走は補助証拠にはなり得るが、野球距離での加速・競技時の実走と同一ではない。

## 2. 直接計測も1軸に潰さない

### 最高走行速度

最高速度側の直接観測。
NPB+ / MLB Statcast等の競技中Sprint Speedは高品質な証拠。

### 一塁到達時間

短距離加速を強く反映するが、次も混ざる。

- 左右打席による一塁までの実距離差
- スイングから走り出すまでの時間
- 一塁駆け抜け
- 打球を見てから走る/全力疾走する行動差

したがって:

```text
home-to-first time != 走力そのもの
```

とし、最高速度と別観測で持つ。

## 3. 得能への分離

### 内野安打○

```text
P(内野安打)
= f(走力, 打球位置/速度/種類, 左右打席, 守備者, ...)
  + player infield-hit skill
```

同じ走力・同じ打球文脈でも内野安打を増やす選手残差を得能へ。
打席から走りへの移行、一塁駆け抜け等をここで吸収する。

### 走塁

```text
追加進塁結果
= f(走力, 打球, 外野手, アウト数, 球場, ...)
  + player baserunning skill
```

残差に入るもの:

- 打球判断
- 進塁判断
- ベースの回り方
- 曲線走
- 減速の少なさ
- スライディング

### 盗塁

```text
盗塁結果
= f(走力, 投手, 捕手, カウント/状況, ...)
  + player stealing skill
```

残差に入るもの:

- 投手を読む
- スタート判断
- リード
- 加速能力の使い方
- スライディング

### 併殺

併殺回避を純粋走力へ直接足さない。

```text
GDP結果
= f(走力, ゴロ難度, 走者状況, 守備位置/併殺能力, ...)
  + player GDP tendency/skill
```

走力で説明した後に残る個人差は、必要なら独自得能または`併殺`赤得能へ。

### 三塁打

純粋走力の直接材料から外す。

混ざるもの:

- 打球方向・深さ
- 二塁打級打球を打つ能力
- 球場形状
- 外野守備
- 走塁判断
- ベースの回り方

速度との相関があっても、速度を直接測る変数としては使わない。

## 4. 新しい構造モデル

最終的には、結果指標から個別に速度を作って平均するのではなく、共通潜在変数を持つ。

```text
latent baseball speed
  ├─> top speed observation
  ├─> home-to-first observation（左右/exit skillを分離）
  ├─> infield-hit result + infield-hit skill
  ├─> extra-base result + baserunning skill
  ├─> steal result + stealing skill
  └─> GDP result + GDP skill
```

直接計測のある2026年選手で `latent baseball speed` をアンカーし、
結果指標は「速度と技術を共同推定するための観測」として使う。
結果指標を固定重みで走力へ直接加算しない。

## 5. 現行モデルを止める理由

旧 `speedComponents` は:

```text
三塁打割合
併殺回避
内野安打率
UBR
（過去には追加進塁）
```

を加重平均していた。

これはいずれも純粋速度以外を含み、特に:

- UBR -> 走塁技術
- 内野安打 -> 打席から走りへの移行等
- 併殺 -> 機会・打球・守備
- 三塁打 -> 打球・球場・走塁

が混入する。

よって、相関や再現性が高くても**定義上の目的変数が違う**。
旧値は研究用legacy evidenceとしてのみ残す。

## 6. 2026-08-07時点の安全ゲート

- `speed_ability.enabled = false`
- `stealing_ability.enabled = false`
- `infield_hit_ability.enabled = false`
- `baserunning_ability.enabled = false`（既に停止済み）

つまり、新しい純粋走力が確定するまでは、旧走力を引いた残差で各得能を確定しない。
観測値・旧計算値・直接計測は消さずevidenceとして保持する。

## 7. 受入条件

1. 最高速度と一塁到達を別観測として扱う。
2. 一塁到達から左右打席・打席から走りへの移行を分離する。
3. 結果指標を走力へ固定加算せず、速度＋技術の共同モデルにする。
4. 2026 NPB+直接計測でplayer-level holdoutを通す。
5. `周東 > 近本 > 源田` を学習ラベルに使わずsanity checkで通す。
6. 高走力・低盗塁、高走力・内野安打得能なし等の組合せを自然に表現できる。
7. 自作エンジンで走力だけを変えたとき、直線走・守備到達・走塁イベントへ一貫した効果を持つ。
