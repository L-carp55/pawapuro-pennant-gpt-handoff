# T-0203 統計材料が薄い選手でNPB+は追加情報を持つか（層別検証）

生成日: 2026-08-13

## 事前に決めたこと（結果を見てから変えていない）

```text
層別の主軸 : weight ＝ poolAcrossYears が返す「プールした各年のPA合計」
             実装に直接ある量。**連続変数**として扱う（log変換・中心化）
層別の副軸 : years ＝ プールした年数。**事前定義カテゴリ 1年 / 2年 / 3年以上**
主要条件   : 2026 advance機会 >= 10（層に分けても人数が残る最小値）
感度       : 5 / 10 / 15
統計側     : maxSeason=2025。2026の情報を一切含まない（漏れ検査つき）
PowerPro   : 一切使わない
```
★層別の軸はどちらも**NPB+を見る前に確定する**。
PowerProとの乖離・NPB+との食い違いは層別に使っていない。

## 判定

```text
全体の増分       -0.061  95%CI [-0.308, +0.208]
層 1年     標本不足(n=2)
層 2年     +0.322  95%CI [-0.337, +0.726]  n=12
層 3年以上   -0.193  95%CI [-0.473, +0.215]  n=38
交互作用         -0.0312  95%CI [-0.0681, 0.0080]
```

### C. 小標本で判定不能

**仮説の対象である「統計材料が最も薄い層（プール1年）」が n=2 で推定できない。**
他の層で増分が無くても、それは「薄い層でも無い」ことを意味しない。
連続の交互作用も95%CIが0を跨ぐため、そちらでも代替できない。

**したがって自動blendしない。** 低reliability選手についてNPB+は
review evidence（人間が見る材料）として残す。

※ 2026年はシーズン途中で走塁機会が少なく、プール1年の選手（＝新人・復帰組）が
　そもそもadvanceの母数を持たない。2026年終了後に再実行すれば判定できる可能性がある。

## 限界

- NPB+は2026年の計測で、当てる2026 advanceと**同年**。NPB+側に「現在の状態を知っている」優位が残る。
  この非対称は消せない。**増分が出ない結論は強く、出る結論は弱い**という向きで読む
- 2026年はシーズン途中でadvanceの機会が少なく、母数が小さい。bootstrapのCIは広い
- 0〜100の絶対目盛りは判定していない（`scale_calibration.走力`のPowerPro依存は別問題）
- 走力は `traitRating` を通らないため、実装内に reliability の値そのものは存在しない。
  同じ役割の量として `weight`（PA合計）を連続変数として使った
