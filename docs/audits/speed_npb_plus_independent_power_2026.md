# NPB+最高速度の独立予測力（PowerProを一切経由しない）

生成日: 2026-08-13

## 何を測ったか

```text
旧: NPB+速度 → (PowerProラベルへ回帰) → 走力点 → blend   ← 現行。これが悪化要因と判明済み
新: NPB+速度 → (実プレー結果へ直接回帰) → 統計材料と同じ空間 → 統合できるか
```
統計側には**窓の制限を掛けていない**（NPB+と同じ特権。窓の非対称で結論が反転する件の対策）。

```text

```

## (3) 統合するならこの形（現実結果ベースの変換）

```text
実プレー結果の合成z = -11.7045 + 0.3728 × NPB+速度(km/h)
相関 r = +0.654   n = 277（全年プール）
```
この式は**PowerProを一切使っていない**。
現行の `npb_plus_direct.models.top_speed_kmh`（PowerProラベルへ回帰したもの）を
置き換える候補になる。ただし採用は下記の判定次第。

## 判定

**NPB+の増分は +0.287（増分あり）。**

統計モデルで説明できる分を除いてもNPB+はなお効いている。
→ **現実結果ベースの空間へ変換したうえで統合する価値がある**。上の(3)の式を使う。

## 限界（この検証が答えていないこと）

- **両側に窓の緩みがある。これは予測試験ではなく「情報が重なっているか」の試験として読む。**
  統計側は mode=Y-1 でも窓が左右対称（±3年）なので、**当てる年Yのデータ自身が予測側に入る**。
  NPB+側は2026年の1点で時点を持たず、絞ることができない。
  したがって両方の絶対値は上振れしている。**比較として意味があるのは偏相関**
  （統計で説明できる分を除いてなおNPB+が効くか）であって、単独の相関値ではない。
- NPB+実測は2026年の1点で時点を持たない。過去年の結果を当てる形になるため、
  **NPB+側に有利な非対称が残る**（窓を絞れない）。その条件での結果として読む
- 統計材料が薄い選手（少出場・1年プール）でNPB+が効くかは、この平均では見えない。
  層別が要る場合は別途測る
- 0〜100の絶対目盛りは一切判定していない
