# 走力の年度プール再設計 — 直接Sprint Speedによる検証

日付: 2026-08-07
状態: **研究完了（現行走力への本番反映は保留）**

## 目的

身体能力だからという理由だけで複数年をPA加重平均する旧方式をやめ、対象年の走力をどう推定するかを実データで決める。

走力の代理指標は別監査で、三塁打を外した

```text
併殺回避 + UBR/PA + 内野安打/in-play
```

の方が2026 NPB+最高走行速度への5-fold CVで同等以上だったため、本監査ではこの3特徴を使う。

## 直接計測から測った年変化

MLB Statcastの年別Sprint Speed（276観測・60人）から、同一選手の年差を測定した。

```text
lag 1年: 142ペア  r=0.939  平均変化=-0.199 ft/s  SD=0.571  MAE=0.468
lag 2年: 102ペア  r=0.904  平均変化=-0.300 ft/s  SD=0.733  MAE=0.622
lag 3年:  74ペア  r=0.905  平均変化=-0.499 ft/s  SD=0.738  MAE=0.701
```

結論:
- 走る速さの順位は年をまたいで非常に安定する。
- しかし能力値自体は動く。PAだけで数年を同じ状態として平均するのは粗い。
- 1年のprocess driftは平均 -0.218 km/h、process SD 0.626 km/h相当。

## 2026 NPB+を使った年度プールのholdout比較

2026 NPB+最高走行速度のうち、2025年の3特徴proxyが作れる96人を5-foldで選手holdoutした。
対象選手の2026直接値は、その選手のproxy回帰の学習には使わない。

比較した方式:

```text
latest   = 直近年だけ
mean3    = 直近3年を対象年へprocess drift分だけ進めて単純平均
paMean3  = 上記をPA加重
kalman   = proxy観測誤差 + MLB直接Sprintのprocess drift/noiseでlatent-state filtering
```

結果:

```text
方式       n   RMSE   MAE    Pearson  Spearman
latest    96  0.985  0.807   0.614     0.609
mean3     96  0.927  0.740   0.712     0.710
paMean3   96  0.904  0.721   0.734     0.740   ← この比較では最良
kalman    96  0.914  0.737   0.727     0.725
```

複雑なlatent-stateモデルが自動的に勝つわけではなく、現時点ではPA加重3年がわずかに良い。
したがって「理論的にきれいだからKalmanを採用」はしない。

## 2024 sanity check

同じlatent-state診断で、2024年までの本人データだけを入れると:

```text
周東佑京  32.90 km/h相当
源田壮亮  32.59 km/h相当
近本光司  32.45 km/h相当
```

オーナー判断のsanity orderは:

```text
周東 > 近本 > 源田
```

なので**不合格**。

重要なのは、年度プールを改善しても近本と源田が逆のままだという点。
したがって現在の主要問題はプール係数ではなく、代理材料が近本と源田の純粋速度差を完全には捉えていないこと。

## 盗塁企図率について

NPB+直接速度との単純相関が高く見えても、走力の材料には戻さない。
2026-08-01のオーナー判断で、速くても盗塁を仕掛けない選手（丸など）がいるため、盗塁企図率は選手・監督・打順・チーム方針を含むとして走力材料から棄却済み。
相関だけを理由に過去の設計判断を覆さない。

## 現時点の判断

1. 三塁打割合は純粋走力の主要材料から外す方向を維持。
2. PA加重3年はholdout上は現候補で最良だが、sanity check不合格なので本番採用しない。
3. `周東 > 近本 > 源田`を手で満たす係数調整は禁止。
4. 近本と源田を分けられる**盗塁行動以外の直接的な速度代理**を追加で探索する。
5. 新モデルが直接計測holdoutとsanity checkの両方を通るまで、現在の走力値はprovisionalとして扱う。
