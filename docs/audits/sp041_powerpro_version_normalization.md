# SP-041 — PowerPro の版正規化・分布・percentile軌跡

生成日: 2026-08-13

## なぜ要るか

「2018年に68、2026年も68だから据え置き」という読みは、**版ごとに走力の分布が動いていない**
ことを前提にしている。版間で分布がずれていれば、同じ68でもリーグ内の位置は違う。
したがって stale 判定（SP-042）の前に、版の正規化と percentile 軌跡が要る。

## 1. 同一日・同一版の重複観測

```text
観測総数            23206
選手×版×日 の組     23192
重複していた組       14
  値が同じ（畳むだけ） 4
  値が食い違う         10
```
正規化規則:

| 状況 | 規則 | 理由 |
|---|---|---|
| 値が全部同じ | 1件へ畳む | 情報は失われない |
| 値が食い違う | **中央値**を採る | 平均だと外れ値1件で動く。畳んだ事実は記録する |

畳んだ記録は `outputs/derived/sp041_powerpro_normalized.json` の `collapsed` に全件保存（14件）。

## 4. SP-042 への申し送り

- stale 判定は**素点の据え置き年数だけ**で決めない。percentile の動きを併せて見る
- 素点据え置き かつ percentile も動いていない → 本当に評価が動いていない
- 素点据え置き だが percentile が動いた → リーグ側が動いた結果で、選手の評価が古いとは限らない
- 版間で中心が動く場合、年跨ぎの「何点上がった/下がった」は percentile で言い直す

## 5. 限界

- 版ごとの分布は**その版に載っている選手の顔ぶれ**にも依存する。
  新人の大量追加や引退で分布が動いた分と、査定方針が動いた分は、この方法では分離できない
- `n>=30` の版だけを対象にした。小さい版は percentile を出していない（0で埋めていない）
