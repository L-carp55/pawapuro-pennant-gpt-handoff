# 走力 オーナーレビュー表 — 2026年 100人

生成日: 2026-08-13

## 先に読んでほしい診断

100人をこちらで査定し、パワプロ2026と突き合わせた結果:

```text
順序の一致（相関）      : 0.830   ← 良い。誰が速いかの並びはほぼ合っている
中心のずれ              : -3.6点   ← 小さい
幅（ばらつき）の比      : 1.67倍   ← ★こちらの幅が狭すぎる
  こちらの幅 9.3 / パワプロの幅 15.5
```

**差の大半は選手個別の問題ではなく、目盛りの幅が違うことの機械的な結果です。**
幅が狭いと、速い選手は自動的に低く・遅い選手は自動的に高く出ます。
この分を引かずにレビューすると、82人分の「差」を1人ずつ見ることになり、
**目盛りの問題を選手ごとに手で直す**ことになってしまいます。

そこで下の表では差を2つに分けました。

- **生の差** = 私の査定 − パワプロ（目盛りのずれを含む）
- **本当の食い違い** = 幅を揃えたうえで残った差。**こちらがレビューの対象**

※ 幅を揃えたのは差を分解するためで、パワプロに合わせて確定したわけではありません。
目盛りの正本はアンカー（別途裁定いただく目安表）で作ります。

## 読み方

- **私の査定** = 実際のプレー結果（三塁打割合・併殺回避・内野安打・進塁・走塁貢献）を
  2021-2025年でまとめた値に、NPB+アプリの実測（最高速度）を確からしさに応じて混ぜたもの
- **内訳** = 「プレー結果だけの値 / NPB+実測だけの値」。**この2つが離れているほど材料が割れている**
- **パワプロの推移** = 2015-2026年の査定履歴。長く据え置きなら「実力が変わったのに直していない」疑い
- **信頼度** = こちらの査定の確からしさ（出場量・使えた年数・材料の食い違いから判定）

**1段目（優先してレビュー）: 28人** / 2段目（余力があれば）: 30人 / 通す: 42人
