## 記入していただくのはこの表だけです

パワーの目安表の走力版です。

```text
パワー: 本塁打20本 → 70点 / 30本 → 80点 / 46本 → 90点
走力  : 一塁到達 ◯秒  → ◯点          ← これを決めたい
```

**「点数」列だけ**を埋めてください。全部でなくて構いません（**3〜4行埋まれば目盛りは作れます**）。

| # | 一塁到達タイム | どのくらいの速さか | **点数** |
|---|---|---|---|
| 1 | **3.75秒** | プロ100人でも上位2%。球界最速級 | |
| 2 | **3.85秒** | 上位1割。誰が見ても速い | |
| 3 | **3.95秒** | 上位4分の1。速い部類 | |
| 4 | **4.05秒** | ちょうど真ん中。平均的 | |
| 5 | **4.15秒** | 下位4分の1。遅い部類 | |
| 6 | **4.25秒** | 下位1割。誰が見ても遅い | |
| 7 | **4.35秒** | 最も遅い部類 | |

「どのくらいの速さか」は、2026年の主力100人を実際に並べた時の位置です（推測ではなく実データ）。

## タイムの意味（読み飛ばして構いません）

**一塁到達タイム** ＝ 打った後にホームベースから一塁まで（約27m）を全力で走ったタイム。
**小さいほど速い**。MLB公式計測（Statcast）で使われている指標で、
NPBでも実測値がある選手が数人います。

実測がある例:

| 選手 | 実測タイム | 計測年 |
|---|---|---|
| カリステ | 3.94秒 | 2017 |
| 秋山 翔吾 | 3.97秒 | 2021 |
| ポランコ | 3.99秒 | 2021 |
| サンタナ | 4.13秒 | 2020 |
| モンテロ | 4.20秒 | 2024 |
| 筒香 嘉智 | 4.20秒 | 2022 |

※ 50m走のタイムは使いませんでした。同じ選手で
「5.99秒（電子計時）」と「5.7秒（方式不明）」のように **0.3秒近く食い違う**ものが多く、
目安の基準に使うと目盛りごと歪むためです。

## 埋めるときの考え方

- 見るのは **純粋な足の速さだけ**です。盗塁のうまさ・走塁判断・内野安打の多さは
  別の能力として既にあるので、**含めないでください**
- **全部埋めなくて構いません。** 「真ん中がだいたい何点か」と
  「速い方がだいたい何点か」の2行だけでも、目盛りの傾きは決まります
- 迷った行は**空欄のまま**にしてください。無理に埋めた数字は目盛りを歪めます
- **幅で答えても構いません**（例: `70〜75`）

### 参考: 感覚がつかみにくい場合

「4.05秒（真ん中）を何点にするか」から決めると楽です。
パワーでは、リーグ平均の打者が50点ではなく44点付近になる設計になっています
（**平均＝50点とは限らない**）。走力も同じで、真ん中を50点にする必要はありません。

## 記入後にCCが行うこと

1. この表を `configs/ratings.json` の `speed_anchors` として正本化
2. 現行の目盛り較正（外部ゲームの分布へ合わせる一次式）を**破棄**し、この表へ当てはめ直す
3. 既存の統計モデル（三塁打割合・併殺回避・内野安打・進塁・UBRを実測した再現性で重み付け）を
   骨格として、この目盛りの上に載せる
4. 物理実測は上書きではなく確からしさに応じて混合
5. 外部ゲームの能力値は **QAとstale検出のみ**（priorには使わない＝裁定②）
6. まず100人、その後全選手（＝裁定③）
