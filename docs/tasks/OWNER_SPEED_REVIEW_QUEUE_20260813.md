## お願いしたいこと

各選手について、次から**1つ選ぶだけ**で構いません。点数を付ける必要はありません。

| 選択肢 | 意味 |
|---|---|
| `POWERPRO_PLAUSIBLE` | PowerProの方が自然 |
| `POWERPRO_TOO_HIGH_OR_STALE` | PowerProが高すぎる／古い査定のまま |
| `POWERPRO_TOO_LOW` | PowerProが低すぎる |
| `PROJECT_TOO_HIGH` | こちらの査定が高すぎる |
| `PROJECT_TOO_LOW` | こちらの査定が低すぎる |
| `BOTH_QUESTIONABLE` | どちらも違和感 |
| `UNRESOLVED` | 判断できない |
| `OTHER` | その他（コメントで） |

点数を書きたい場合だけ「◯点」と添えてください。**必須ではありません。**
