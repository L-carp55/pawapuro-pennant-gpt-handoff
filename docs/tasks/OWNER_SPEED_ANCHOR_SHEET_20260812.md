## 0. これは何をするものか

**「走力◯点とはどれくらいの速さか」の目安表**を作ります。
パワーに `20本→70点 / 30本→80点 / 46本→90点` という目安があるのと同じものを、走力にも作ります。

今これが無いため、走力は**外部ゲームの能力値に合わせる以外の基準を持っていません**。
オーナーがこの表を埋めた時点で、それが走力の目盛りの正本になります。

### 記入のしかた

下の表の **「あなたの点数」列だけ**を埋めてください。

- **全部埋める必要はありません。** 自信のある選手だけで構いません（5〜6人でも成立します）
- 迷ったら**空欄のまま**にしてください。無理に埋めた点数は目盛りを歪めます
- **幅で答えても構いません**（例: `70〜75`）

### 何を評価するか（重要）

走力は**純粋な足の速さ**だけです。次は**含めないでください**（別の能力として既にあります）:

- 盗塁がうまい／スタートが良い → **盗塁**の能力
- 次の塁を狙う判断が良い → **走塁**の能力
- 内野安打が多い → 打席から走り出す技術が混ざるので**別**

見るのは「**全力で走った時、単純にどれくらい速いか**」だけです。

## 1. 記入前に知っておいてほしいこと

### 現行の「暫定値」は、実質1つの数字だけで決まっています

100人の暫定値を検算したところ、**例外なく次の式そのものでした**:

```text
暫定値 = -218.09 + 8.975 × NPB+の最高速度(km/h)
相関 r = 1.000000 / 最大のズレ 0.0005点（99人全員）
```

つまり、集めた**物理実測459件・SNS・映像・過去データは、点数に1ミリも効いていません**
（唯一の例外がモンテロで、直接計測を見て手で下げた1件だけ）。

### 実測と暫定値が食い違っている実例

| 選手 | 実測タイム | 暫定値 |
|---|---|---|
| モンテロ | **T90 4.20秒**（2024） | **68.2** |
| 筒香 嘉智 | **T90 4.20秒**（2022） | **53.0** |
| 秋山 翔吾 | **T90 3.97秒**（2021・モンテロより速い） | **65.5** |

**同じ4.20秒で15点差**、しかも**より速い秋山の方が低い**。
実測が使われていないので、こうなります。

→ だからこそ、**オーナーの点数が基準として要ります**。

### 補足: T90 と 50m の読み方

- **T90** = ホームから約27m（90フィート）を走るタイム。**小さいほど速い**。MLB公式計測（Statcast）
- **50m** = 50m走。**小さいほど速い**。ただし電子計時と手動・年不明が混在
- **NPB+速度** = 全力疾走時の最高速度(km/h)。**大きいほど速い**

## 4. 記入後にCC側が行うこと

1. この表を `configs/ratings.json` の `speed_anchors` として正本化する
2. 現行の目盛り較正（`scale_calibration.走力` = 外部ゲームの分布に合わせる一次式）を**破棄**し、
   このアンカーへ当てはめ直す
3. 既存の統計モデル（三塁打割合・併殺回避・内野安打・進塁・UBR を実測した再現性で重み付け）を
   骨格として、このアンカー上に載せる
4. 物理実測は「上書き」ではなく確からしさに応じた混合で足す
5. 外部ゲームの能力値は **QAとstale検出のみ**に使う（priorには使わない＝2026-08-12裁定②）
6. まず100人、その後全選手へ展開（＝2026-08-12裁定③）

## 5. 注意（CCからの申し送り）

- **この表には外部ゲームの能力値を載せていません。** 載せるとアンカーがそれに引きずられ、
  「外部に合わせない基準を作る」という目的そのものが壊れるためです。
  記入後のQAでは並べて比較します。もし記入時にも見たい場合は言ってください（再発行します）
- **T90の年に注意**: 秋山2021・カリステ2017・ポランコ2021 は数年前の計測です。
  当時から変わっている可能性があるので、**現在の印象を優先**してください
- 埋まった点数が5人未満だと目盛りが安定しません。その場合は§3で選手を足していただけると助かります
