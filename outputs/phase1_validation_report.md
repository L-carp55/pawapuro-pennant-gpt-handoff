- 合計打数 23,621 / 合計打席 27,073

## 4. データ上の注意点

- **ゲームタイプが4種混在**: 公式戦 / CSファースト / CSファイナル / 日本シリーズ。査定は`game_type='公式戦'`に限定すること
- 投球回はNPB表記（"46.2" = 46回2/3）。DBにはアウト数(`outs`)へ変換して格納。元表記も`ip_text`に保持
- 欠損は0でなくnullで保持（捕逸は捕手以外null等）
