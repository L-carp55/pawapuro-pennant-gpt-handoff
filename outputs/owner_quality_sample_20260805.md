# オーナー品質確認サンプル — 10選手・2024年（改訂版2）

生成日: 2026-08-06

**パワプロの値は採否の物差しではない**（2026-07-31確定）。ここでは「査定の出力が
常識的な範囲に収まっているか」を目視確認する参考としてのみ横に並べる。

## 計算方法の説明

5つの数字（基準打率・本塁打率・肩力・守備力・捕球）が、それぞれ何を混ぜて
出ているかを説明する。個別の選手の実際の数字は「個別の詳細」で同じ手順を辿れる。

### ミートの元になる「基準打率」

村上宗隆の2024年で言うと、打率.244（500打数122安打）という数字がある。
だがミートの計算はこの.244をそのまま使わない。手順は4段階。

**1. 対戦相手を絞る。** 右投手と対戦した時の成績だけを取り出す（左投手の成績は
別枠で扱う。「対左投手」という別の得能になる）。これが「基準打率」。村上の場合、
327打数で.217——全体の.244より低い。これは対左投手の方が調子が良く、右投手だけ
見ると低く出ているため。★対戦相手を絞った分割成績が無い年（2005年以前など）は、
打率全体をそのまま使う。

**2. その年のリーグ水準に合わせて底上げ・割引する（年度補正）。** 同じ.217でも、
リーグ全体の打率が低い年に出した.217と、高い年に出した.217では価値が違う。
2019年を基準の年と決め、**対象年の「対右投手」のリーグ平均と、2019年の「対右投手」の
リーグ平均**を比べて、差の分だけ底上げ・割引する。★比べる相手も同じ対戦条件で
揃える（2026-08-05に修理。以前は対象年だけ対右・基準年は総合を使っており、環境の差を
小さく見積もっていた）。なお環境が1%動いても打者の打率は0.91%しか動かない、と
実測されているため、補正はそのぶん弱めにかける。

**3. 出場が少ない年だけ、本人の実績と混ぜる（縮小）。** ★2026-08-05にオーナー指示で
全面変更した——「基本的にはその年だけで査定してください。過去の実績から補正が入るのは
成績が明らかに下振れたときとけがなどであまり出られなかったときだけです」。
**その年に十分出場していれば（打数359以上）、その年の成績をそのまま使う**（混ぜない）。
出場が少ない年だけ、不足した打数の分だけ本人の直近実績へ寄せる。
閾値359は恣意的な数字ではなく、規定打席（試合数×3.1=443）に到達した845人年
（2010-2025）の打数の最小値を取ったもの。

※変更前は全選手に一律の縮小がかかっており、フル出場の選手でも本人の過去実績が
4割前後混ざっていた。年度ごとの査定としては誤りだった。

**4. リーグ平均と比べて点数にする。** ここで出来た数字を、同じ年・同じ対戦相手条件の
リーグ平均と比べて点数化する。★2026-08-06修理: 以前はこの後に「パワプロ143人の分布に
合わせる」という段が入っていたが、これを**廃止した**（後述）。

★得点圏（チャンス）の扱いについて: 本来は「得点圏で特別強い分はチャンス得能へ移し、
ミートからは引く」のが仕様の意図（仕様05 §2）。だが対右投手の打率を基準にしている
場合、引くには「対右投手の中での得点圏の成績」が必要で、そのデータが公開されていない。
総合打率ベースの得点圏差を代わりに使うと母集団の違うものを引くことになるため、
**Tier B（対右投手が基準）では引かない**（2026-08-05にオーナー指摘で修理）。
結果として、対右投手の打率には得点圏の成分が残っている。

### パワーの元になる「本塁打率」

本塁打率も同じ考え方で4段階を通る。村上2024年で言うと本塁打33本／500打数=6.6%。

**1. 打数のばらつきを揃える。** 打席数が多い選手ほど本塁打の絶対数は増えやすいので、
「打数490（規定打席に達する選手の平均的な打数）あたり何本か」に換算する。
**2. 球場補正。** 本拠地によって本塁打の出やすさが大きく違う（神宮球場は平均の
1.86倍、バンテリンドームは0.60倍、というように）。実際にどの球場で何打数立ったかを
調べ、加重平均した係数で本塁打率を割り引く（打ちやすい球場の本塁打ほど価値を下げる）。
**3. 年度補正。** 打率と同じくその年のリーグの本塁打率を2019年基準に合わせる。
本塁打は選手の実力による差が大きいほど環境の影響を受けにくいと実測されているため、
補正の強さは選手の水準によって変える（強打者ほど補正を弱める）。
**4. 点数化。** 出来上がった「本塁打◯本相当」を、目安の表に当てはめて点数にする——
**20本→70 / 30本→80 / 40本→86.5 / 46本→90**（間は線でつなぐ）。★打率と同じく、
その年に十分出場していれば本人の過去実績とは混ぜない（2026-08-05オーナー指示）。
出場が少ない年だけ、不足した打数の分だけ本人の実績へ寄せる。

#### ★2026-08-06 修理: 目安の表が2つの経路から壊されていた

オーナー指摘「35.89本相当でパワーが80行かないのもおかしい」「前言ったホームランの
本数とパワーのざっくりとした目安を覚えていますか？」で発覚。上の目安（20本→70 /
30本→80 / 46本→90）は正本に入っていたのに、**その後ろで2つの処理が値を書き換えて
いた**。どちらもパワプロの能力値を目盛りにしている。

**① パワプロ143人への分布合わせ**（2026-08-01導入）。傾き0.679・切片17.77の一次式を
最後に掛けていた。この式を目安の表そのものに当てると **20本 70→65.3 / 30本 80→72.1 /
46本 90→78.9 / 56本 100→85.7** となり、本塁打王級の46本ですら90に届かない。
目安はどこも成立していなかった。村上のパワーはこれで83.8→74.7に落ちていた。

**② NPB+実測の混合**。ハードヒット率などから能力値を出す式だが、その式は
`SELECT power FROM pawapuro_full`——つまり**パワプロの能力値を目標に当てはめたもの**で、
出てくるのは「パワプロの目盛りの上の点数」。これを52%の重みで混ぜていた。
実害: 山川穂高2024は素点88.5（オーナーが2026-07-31に「89.8で妥当」と裁定した水準）
だったのに、78.9まで下がっていた。**オーナー自身の裁定が上書きされていた。**

**なぜ起きたか**: 2026-08-01に走力の目盛りずれを見つけた時、「相関0.4以上の能力は
分布を合わせる」という一律ルールを4能力に当てた。このとき**その能力が既に正本で
目盛りを決められているかを確認しなかった**。走力・弾道には目安の表が無く、
「リーグ平均=50」という未検証の仮置きだったので、分布合わせが唯一の根拠として妥当。
ミート・パワーには目安の表があり、しかもオーナーが個別に裁定していた。

**直した内容**: ミート・パワーには①②のどちらも当てない（目安の表が唯一の目盛り）。
走力・弾道には引き続き当てる（目盛りの根拠がそこにしか無いため）。
NPB+の実測そのものを捨てたわけではなく、捨てたのは「パワプロの目盛りへの変換式」。
正しい直し方＝ハードヒット率→**本塁打率**を当てはめ、その本塁打率を目安の表へ通す
（目盛りの出所を1つにする）。それまでは適用しない＝T-0147として登録した。

**パワプロとの誤差はこの修理で増える**（パワー5.33→8.61）。だがパワプロは正解では
ないので、誤差が増えたことを撤回の理由にしない（2026-07-31オーナー確定「KONAMI比較は
参考チェックに格下げ」）。

### 肩力（送球の強さ）

経路が2つある。**①実測がある場合**: 外野手・捕手の一部は、送球でどれだけ
走者をアウトにできたかという公式の高度統計（ARM）と、実際にアウトにした補殺の
数の2つを組み合わせて測る。1年だけでなく直近数年分を平均する（肩の強さは1年で
大きく変わらないため）。**②実測が無い場合（多くの内野手）**: NPBの公開データには
内野手の送球速度そのものが無いため、代わりに「どの守備位置を守れているか」から
推定する（遊撃を守れる選手は肩が強いはず、という考え方）。★この推定方式は、
今日DELTA社の実測データで答え合わせしたところ**当てずっぽうに近い**（実際の送球の
強さとの一致がほぼ無い）と判明した。内野手の肩力は実測が無い限り参考程度に見てほしい。

### 守備力（どこまで打球に追いつけるか）

公式の高度統計（RngR＝守備範囲によってどれだけアウトを稼いだか）を使う。
そのまま使うと「足が速いから広く守れる」のか「守備の判断が上手いから広く守れる」
のかが混ざってしまうので、**まず選手の脚の速さ（走力）から「この速さなら普通は
これくらい守れるはず」という基準値を計算し、実際の記録からその基準値を引く**。
残った差（残差）だけを守備の巧さとして評価する。加えて、2026年に追加した材料として
併殺（ダブルプレー）で始める役・中継する役をどれだけ果たしたかも二塁手・遊撃手には
加味する（これは守備範囲そのものではなく別の技術だが、翌年への再現性が高いことを
確認したうえで追加した）。出場イニングが少ないとこの評価は中央値（50点）へ
寄せられる（信頼度が下がるため）。

### 捕球（打球やゴロを確実に処理できるか）

選手によって経路が3つある。**①捕手**: 捕逸（ワンバウンドの投球を後ろへ逸らして
走者を進めてしまうこと）の少なさで測る。公式の失策数より、こちらの方が
捕手本人の実力を年をまたいで安定して映すと実測で確認できたため。**②送球の正確さが
確定している29選手（後述）**: 失策を「送球のミス」と「それ以外（捕球・処理の
ミス）」に分けた記録があるので、そのうち「それ以外」だけを使う。理由は、送球の
ミスは別の能力（送球という得能）として既に評価しているため、両方に失策の数を
使うと同じ情報を二重に数えることになるから。**③それ以外の選手**: 通常の失策数の
高度統計（ErrR）をそのまま使う。守備位置・年ごとの平均と比べ、出場量に応じて
中央値へ寄せる。

**パターンA（捕球の縮小が強い）** — 近本・源田・甲斐・岡本・菊池・村上の6件すべて。
捕球（ErrR/捕逸ベース）は翌年再現性が低いため（実測r=0.208）、信頼度が低く抑えられて
いる（kappa=3426イニング。レギュラー級の出場でも信頼度は0.22〜0.27にしかならない）。
少ない信頼度の分だけ中央値（50点）へ寄せる仕組みなので、ほぼ全選手の捕球が45〜58点の
狭い範囲に収まる。パワプロは評判も含めて0〜100いっぱいに散らすため、守備の評判が
高い選手（近本・源田・甲斐）は自作が低く出て、評判が低い選手（村上）は自作が高く出る
——**同じ1つの原因が両方向の乖離を作る**。信頼度そのものは仕様の実測較正（別の材料の
翌年再現性から逆算）なので、値を大きく動かすには縮小の強さ自体を見直す必要がある。

**パターンB（内野手の肩は推定であり実測でない）** — 牧秀悟の肩力差(-13.3)。
二塁・三塁・遊撃・一塁は肩力の直接実測（ARM）が無いことが多く、「守れる守備位置」から

## Q&A: 村上宗隆の基準打率はなぜ低いのか

★このQ&Aはオーナー指摘（2026-08-05）を受けて **3件を修理した後** の値で書いている。
修理前はミート52.2点、修理後は38.2点（パワプロ41）。

村上の「基準打率」は **.217**（対右投手・327打数）。
全体の打率.244より低いのは、対左投手の方が調子が良く（.295）、右投手だけに絞ると
低く出ているため。これは対右投手との対戦成績そのものであり、査定はこれを使う。

実際の計算は次の順で進む:

```
.217（対右投手のみ、327打数）
  → 年度補正で.226（対右投手どうしで比較。2024年.2465 / 2019年.2580）
  → 縮小なし（500打数 ≧ 十分出場とみなす359打数
     ＝縮小係数κ=0。その年の成績をそのまま使う）→ .226
  → 対右投手のリーグ平均（.246）と比べて38.2点
  → 加減点後38.2点
  → 最終38.2点（★2026-08-06にパワプロ分布合わせを廃止したので、加減点後の値がそのまま出る）
```

★以前は「本人の直近4年の実績（打率.286）と半々で混ぜて.253」という段が入っていた。
オーナー指示（2026-08-05）で「基本的にはその年だけで査定」に変更したため、
十分出場した村上にはこの段が無くなり、対右の.226がそのまま使われるようになった。

### 修理した3件（オーナー指摘で発見）

**① 得点圏の調整が、母集団の違うものを引いていた**。
「得点圏で強い分はチャンス得能へ移し、ミートからは引く」という調整（仕様05 §2）が
入っていたが、その計算は**総合打率(.244)から得点圏差を引いた値**を、**対右投手の
打率(.217)から作った基準**と比べていた。母集団が違うものの引き算になっており、
村上の場合 +3.55点を加算していた——だがその中身は得点圏の効果ではなく
**.244と.217の差(27厘)がそのまま出たもの**だった。村上は得点圏.273／非得点圏.233と
得点圏に強い選手なので、仕様の意図ではミートは**下がる**はずで、符号すら逆だった。
正しく引くには「対右投手の中での得点圏差」が要るが、公開データに交差セル
（対右×得点圏）は無く、仕様02 §5.1が周辺値からの復元を禁じている。よって**引かない**
ことにした。対右の打率に得点圏の成分は残るが、母集団の違うものを引く誤りよりは正しい。

**② 年度補正の比較相手が片方だけ総合打率だった**。
対象年のリーグ平均は「対右投手」(.2465)を使っていたのに、基準年(2019年)は
**総合**(.2521)を使っていた。対右どうしで揃えると2019年は.2580で、環境の差は
3.79%→**4.67%**と大きくなる。村上の基準打率は.222→.226へ約4厘上がった。

**③ 縮小が全選手に一律かかっており、年度ごとの査定になっていなかった**
（指摘「あくまで年度ごとの査定ですよ？」「翌年再現性は一年ごとの能力を査定するのに
完全に不要です」）。従来の縮小の強さは**翌年の成績を当てる誤差を最小にする**値で
決めていたため、フル出場の選手でも本人の過去実績が4割前後混ざっていた。
年度ごとの査定という目的には合っていない。
→ **その年に十分出場していれば（打数359以上）縮小しない**方式に変更。
過去を参照するのは出場が少なかった年だけになった（＝けが等で出られなかった場合）。
閾値359は規定打席到達者845人年の打数の最小値（実データ由来）。

**3件を直した効果（141人全体・パワプロとの比較）**:

| | 修理前 | ①②修理後 | ③も修理後（現在） |
|---|---|---|---|
| ミート順位相関 | 0.756 | 0.791 | 0.774 |
| ミート平均誤差 | 5.2 | 5.1 | 6.0 |
| 村上のミート | 52.2 | 49.5 | 38.2（パワプロ41） |

★③の変更でパワプロとの一致は下がった。ただし**これは方針の帰結であって欠陥ではない**。
パワプロの能力値は複数年の評判を含んだ「その選手のイメージ」であり、
「その年だけの成績」とは本来ずれる。村上個人で見ると 49.5→38.2 とパワプロ41へ近づいており、
単年で見た時の再現性はむしろ上がっている。パワプロは採否の物差しにしない
（2026-07-31確定）ので、この数字を理由に方針を戻すことはしない。
