## 現状

- 全40枚のうち **評価が入っているのは 3枚**（鈴木誠也のみ）。残りは統計のまま
- 走力の統計は2026-08-01に改善済み（内野安打率を追加／三塁打割合へ変更／材料の質で重み付け → 翌年再現性 0.755→0.791）
- 走力の「データなし」はNPB Basementの範囲外（2019年以前）。**肩力は補殺で2006年まで遡れる**
- **肩力は無料データでは打ち止め**（ARM・補殺とも「強肩ほど走者が走ってこない」構造の影響を受ける）
- 全カードは 作り直し 40件 / 失敗 0件 で一度に作り直せる（古い版が混ざらないように）

## 直し方

`configs/scouting.json` の `entries` に足す。`evaluator`（誰が）と `basis`（何を根拠に）は必須で、
どちらかが欠けると読み込みの時点で全体が止まる（根拠のない数字が紛れ込まないようにするため）。

```json
{
  "player": "丸　佳浩",
  "season": null,
  "ability": "肩力",
  "value": 75,
  "evaluator": "owner",
  "basis": "なぜその値か。ここが空だと受け付けない",
  "dated": "2026-08-01"
}
```

- `player` は登録名（全角スペース区切り）。`ability` は `走力` か `肩力`
- `season` を `null` にすると全年に適用される。脚力・肩は年で変わらないので**こちらが既定**。
  衰えを表現したい時だけ年を指定する
- `evaluator` は `measured`（実測）／`owner`（オーナー評価）／`scouting_doc`（公表資料）／
  `external_ai`（GPT等）／`konami`（パワプロの値）の5種
- 足したら `node scripts/build_cards_batch.mjs all peak` で全カードに反映される
